## Elata 是什么

Elata 是一个用于构建和使用面向消费者的生物传感、神经科学和认知应用的平台，尊重用户隐私。

- **Elata**（[app.elata.bio](https://app.elata.bio)）是用户在浏览器中发现和使用应用、开发者发布应用的地方。
- **[Elata SDK](/cn/overview/elata-sdk)** 是一组开源软件包，可将网络摄像头或消费级头带变成生物信号传感器，在用户自己的设备上处理信号。
- **隐私从设备端开始。** 原始信号在本地处理。Elata 可以存储应用存档、事件记录、分数和付款记录；派生结果只有经过同意才能贡献到跨应用生物特征评分。你可以撤销同意并请求删除数据。[你的数据](/cn/users/your-data)说明了不同的存储和删除方式。

开始使用时，_不需要专用硬件_：摄像头应用可以使用你已有的网络摄像头或手机摄像头。

Elata 应用可以将普通网络摄像头或手机摄像头变成生物传感器，根据面部和行为的细微变化测量或估计心率、心率变异性、呼吸频率、眨眼频率、情感状态等信号。

可用输出及其可靠性取决于应用、传感器、软件包版本、信号质量和算法。心率、HRV、呼吸估计和基于面部的情感估计是不同的信号；生理激活评分并不直接测量情绪。参见[生物信号说明](/cn/overview/biosignals)和[SDK 输出指南](/cn/sdk/rppg-web/getting-started#output-and-quality-guidance)。

我们也支持通过网络读取脑活动的应用。这些应用需要 [Muse](https://choosemuse.com/) 等消费级 EEG 设备。

<Note>
Elata 应用用于健康生活、游戏、学习和研究。它们不是医疗器械，也不诊断或治疗任何疾病。参见[安全与局限](/cn/users/safety-and-limitations)。
</Note>

<a id="building-technology-thats-open-transparent-and-private"></a>

## 构建开放、透明且尊重隐私的技术

Elata 以开源软件、透明实验为基础，希望生物传感技术对使用者而言易于理解、可以检查、可以扩展，并尊重隐私。

Elata 背后的许多技术在 GitHub 上公开开发，包括支持当前应用的 SDK，以及帮助塑造 Elata 的早期实验。

两个值得了解的例子：

- [**Elata EEG**](https://github.com/Elata-Biosciences/elata-eeg) 是我们构建低成本、可维修开源 EEG 硬件的项目，用于神经科学研究和有趣的 DIY 脑机接口（BCI）项目，例如我们于 2025 年在新加坡举办的[脑控游戏比赛](https://x.com/DeSciWorld/status/1978762697022865576?s=20)。
- [**ZORP**](https://github.com/Elata-Biosciences/zorp) 是我们探索无需许可的研究基础设施的实验，用于收集数据、协调科学研究并奖励参与者。

并非每个实验都会成为当前产品的一部分，但我们保留这些公开成果，因为有价值的想法、代码和研究不应随着项目转向而消失。

你可以在 [GitHub](https://github.com/Elata-Biosciences) 上探索我们当前和过去的工作。

<a id="how-to-read-these-docs"></a>

## 如何阅读文档

文档中的功能标有状态，方便你判断目前可以使用什么：

| 标签 | 含义 |
| --- | --- |
| **已上线** | 目前对所有人开放。 |
| **实验性** | 可以使用，但可能变化或存在限制，例如仅以源码提供的软件包。 |
| **计划中** | 正在探索的方向，尚不可用，细节可能变化。 |
| **已退役** | 曾经存在但已移除，仅为旧链接保留说明。 |

尚未全面上线的页面在侧边栏中有标签。完整清单见[状态](/cn/overview/status)页面。

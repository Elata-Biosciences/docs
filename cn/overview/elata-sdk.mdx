<a id="what-it-does"></a>

## 功能

Elata SDK 是一组开源 JavaScript 包，用于基于生物信号构建应用程序。它处理困难的部分：

- **将** 连接到设备：网络摄像头或蓝牙 EEG 头带，例如 Muse
- **将** 原始信号处理为可用的测量值：心率、心率变异性、 EEG 频段功率、信号质量
- **在设备上运行**：处理核心是用 Rust 编写并编译为 WebAssembly，因此它在浏览器中运行，原始数据不必发送到服务器

该 SDK 免费使用，发布于 [npm](https://www.npmjs.com/org/elata-biosciences)，并在 [GitHub](https://github.com/Elata-Biosciences/elata-bio-sdk)上公开开发。

<a id="package-families"></a>

## 套餐家庭

| 家庭 | 套餐 | 状态 |
| --- | --- | --- |
| **传感器** | `rppg-web` （网络摄像头心率）、 `eeg-web` （EEG 处理）、 `eeg-web-ble` （蓝牙头带）、 `ppg-web` （头带心率） | 已上线 |
| **Elata平台** | `app-payments` （购买）， `app-metrics` （记录和分数） | 已上线 |
|| `app-state` （已保存进度） | 实验性 |
| **记录与分析** | `biosignal-session` （本地会话记录）、 `biosignal-analytics` （功能和分数）、 `rppg-models-web` （学习的波形模型） | 实验性 |
| **工装** | `create-elata-demo` （入门应用程序） | 实时已知问题 |

“实验性”包可作为源代码提供，但尚未在 npm 上提供。请参阅 [直播内容](/cn/overview/status)。

<a id="supported-devices"></a>

## 支持的设备

| 设备 | 信号 | 浏览器 |
| --- | --- | --- |
| 任何网络摄像头 | 脉冲 (rPPG) | 现代浏览器 |
| Muse 2 和 Muse S | 4通道 EEG， PPG | Chrome 或 Edge（网络蓝牙） |
| 缪斯S（雅典娜） | 8通道 EEG，光学，运动 | Chrome 或 Edge（网络蓝牙） |

可以通过SDK的设备合约添加其他耳机。请参阅 [设备集成](/cn/integrate)。

---

<a id="you-dont-have-to-publish-on-elata"></a>

## 您不必在 Elata 上发布

该 SDK 适用于任何网络应用程序。在 Elata 上发布增加了分发、帐户和付款，但传感器包不需要它。

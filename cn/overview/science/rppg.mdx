<a id="the-principle"></a>

## 原理

随着每次心跳，皮肤中的血量都会上升和下降。血液会吸收光线，因此皮肤的颜色会随着脉搏的变化而发生轻微的变化。即使肉眼看不见，相机也可以检测到这种变化。非接触式测量称为 **远程光电体积描记法（rPPG）**。

---

<a id="how-the-elata-sdk-does-it"></a>

## Elata SDK 是如何做到的

`rppg-web` 在用户设备上的浏览器中运行此管道：

1. **找到面孔。** 面部标志模型定位前额和脸颊等皮肤区域。
2. **平均颜色。** 对于每个视频帧，SDK 会对这些区域中的红色、绿色和蓝色值进行平均。
3. **提取脉冲信号。** 已建立的方法结合颜色通道来消除照明和运动：绿色通道方法、CHROM（基于色度）和 POS（平面正交于皮肤）。
4. **估计汇率。** SDK 通过两种方式估计每分钟节拍数：信号的频谱和自相关，并检查它们是否一致。
5. **报告质量。** 每个估计值都带有信号质量值和置信度值，因此应用程序可以区分清晰的读数和猜测。

原始视频帧永远不会离开设备。

<a id="what-affects-accuracy"></a>

## 什么影响准确性

rPPG 在良好条件下工作良好，在恶劣条件下性能下降。已发表的评论一致指出了相同的挑战：

| 因素 | 为什么这很重要 |
| --- | --- |
| **运动** | 头部运动会改变光线照射皮肤的方式，从而淹没脉搏信号 |
| **照明** | 昏暗、不均匀或闪烁的灯光（某些 LED 灯和荧光灯）会增加噪音 |
| **肤色** | 深色皮肤吸收更多光线，从而降低光学方法的信号幅度 |
| **相机和压缩** | 低帧速率和重度视频压缩消除了微小的颜色变化 rPPG 取决于 |
| **距离和取景** | 皮肤像素越少意味着信号越弱 |

用户提示位于 [设备](/cn/users/devices)。构建者可以使用 SDK 的质量和置信度值来提示用户或阻止读取。

<a id="what-rppg-can-and-cant-claim"></a>

## rPPG 可以索取什么，不可以索取什么

- **可以：** 在合理条件下估算静息脉率，并显示信号的稳定性。
- **请注意：** 摄像头的心率变化需要非常干净、较长的记录。
- **不能：** 诊断心律问题或更换医疗设备。即使是智能手表中使用的联系人 PPG，也需要心电图确认才能诊断。

<a id="contact-ppg"></a>

## 联系方式 PPG

**光电体积描记法 (PPG)** 将光线照射到皮肤并测量返回的量。当血量随着每次心跳而脉动时，反射光就会发生变化。它的原理与 rPPG相同，但传感器接触皮肤，从而发出更强的信号。智能手表和一些头带（例如 Muse S）都使用它。

Elata SDK 的 `ppg-web` 包通过网络蓝牙读取头带的光学传感器，并估计设备上的心率和心率变异性。

<a id="heart-rate-variability-hrv"></a>

## 心率变异性 (HRV)

你的心脏不像节拍器那样跳动。心跳之间的时间因心跳而异，该变化为 **心率变异性**。休息时较高的 HRV 通常与恢复和放松有关，而较低的 HRV 则与压力或疲劳有关，尽管它也随着年龄、健康状况、呼吸和一天中的时间而变化。

SDK 报告两种常见的时域测量：

| 测量 | 它是什么 |
| --- | --- |
| **RMSSD** | 节拍之间连续差异的均方根。反映短期的逐搏变化。 |
| **SDNN** | 记录中节拍间隔的标准偏差。反映整体变化。 |

严格来说，从 PPG 测量的变异性是 **脉率变异性**。它密切跟踪静息时基于心电图的 HRV ，但两者并不总是可以互换的。

<a id="what-makes-hrv-meaningful"></a>

## 是什么让 HRV 有意义

| 条件 | 为什么 |
| --- | --- |
| **休息时** | 可穿戴设备与基于心电图的 HRV 在休息时的一致性非常好到优秀，随着活动的增加而下降 |
| **足够长** | 一分钟或更长时间的干净数据；几秒钟还不够 |
| **干净节拍检测** | 丢失或额外的节拍会严重扭曲 RMSSD，因此必须排除噪声片段 |
| **与自己相比** | HRV 人与人之间差异很大；根据您自己的基线得出的趋势比绝对数字更能提供信息 |

当 SDK 无法可靠地检测节拍时，它会保留 HRV 值（不返回任何值），而不是报告误导性的数字。

---

<a id="what-it-cant-claim"></a>

## 它不能主张什么

基于PPG的心率被广泛使用，并且在休息时通常是准确的。它不能诊断心律失常或其他心脏疾病：已发表的评论指出，心电图确认对于诊断仍然是必要的。

<a id="contact-ppg"></a>

## 联系方式 PPG

**光电体积描记法 (PPG)** 将光线照射到皮肤并测量多少
回来了。当血量随着每次心跳而脉动时，反射光
变化。和 rPPG原理一样，但是传感器接触皮肤，
这给出了更强的信号。智能手表使用它，有些也使用它
头带，例如 Muse S。

 Elata SDK的 `ppg-web` 包通过网络读取头带的光学传感器
蓝牙并在设备上估计心率和心率变异性。

<a id="heart-rate-variability-hrv"></a>

## 心率变异性 (HRV)

你的心脏不像节拍器那样跳动。节拍之间的时间不同
心跳与心跳之间略有差异，这种变化是 **心率变异性**。
休息时较高的 HRV 通常与恢复和放松有关，而较低的 HRV
则与压力或疲劳有关，尽管它也随年龄、健康状况、呼吸、
和一天中的时间。

 SDK 报告了两种常见的时域测量：

| 测量 | 它是什么 |
| --- | --- |
| **RMSSD** | 节拍之间连续差值的均方根。反映短期的逐搏变化。 |
| **SDNN** | 记录中节拍间隔的标准偏差。反映整体变化。 |

严格来说，从 PPG 测量的变异性是 **脉率变异性**。它
密切跟踪静息时基于心电图的 HRV ，但两者并不总是相同
可互换。

<a id="what-makes-hrv-meaningful"></a>

## 是什么让 HRV 有意义

| 状况 | 为什么 |
| --- | --- |
| **休息时** | 可穿戴设备与基于心电图的一致性 HRV 休息时非常好到优秀，随着活动的增加而下降 |
| **足够长** | 一分钟或更长时间的干净数据；几秒钟还不够 |
| **干净的节拍检测** | 一个丢失或额外的节拍会严重扭曲 RMSSD，因此必须排除噪声片段 |
| **与自己相比** | HRV 人与人之间差异很大；根据您自己的基线进行的趋势比绝对数字更能提供信息 |

当无法检测节拍时， SDK 会保留 HRV 值（不返回任何值）
可靠地，而不是报告误导性的数字。

---

<a id="what-it-cant-claim"></a>

## 不能索取的东西

基于PPG的心率被广泛使用，并且在休息时通常是准确的。确实如此
不诊断心律失常或其他心脏病：已发表的评论指出
诊断仍需心电图确认。

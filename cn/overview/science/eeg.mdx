<a id="the-principle"></a>

## 原理

神经元通过微小的电流进行通信。当大群人开火时
头皮上的传感器可以检测到组合活动。那
记录的是 **脑电图（EEG）**。它以节奏为主
不同频率：

| 乐队 | 约。范围 | 通常与 |相关
| --- | --- | --- |
| Delta | 1–4 Hz | 深度睡眠 |
| Theta | 4–8 Hz | 困倦，一些记忆任务 |
| Alpha | 8–12 Hz | 放松的清醒状态，尤其是闭眼时 |
| Beta | 13–30 Hz | 思维活跃，警觉性 |
| 伽玛 | 30+ Hz | 快速处理；也受到肌肉活动的严重污染 |

这些关联是人群之间的倾向，而不是任何人的规则
单一的时刻。

<a id="consumer-headbands"></a>

## 消费类头带

 Elata SDK 支持 Muse 系列超过 Web Bluetooth：

| 设备 | EEG 通道 | 传感器位置 |
| --- | --- | --- |
| Muse 2、 Muse S | 4 | 耳后（TP9、TP10）和额头（AF7、AF8） |
| Muse S (Athena) | 8 | 新协议上的附加通道 |

研究级系统在盖子中使用 32 至 256 个湿电极。头带使用
固定位置的少数干传感器。这使得它变得舒适并且
负担得起，并且限制了它可以测量的范围。

<a id="how-the-elata-sdk-processes-eeg"></a>

##  Elata SDK 如何处理 EEG

`eeg-web` 使用 WebAssembly在浏览器中运行：

- **滤波和频谱：** 去除漂移和线路噪声，并计算每个窗口的频谱
- **频段功率：** 每个频段和通道的绝对功率、相对功率和对数功率
- **质量标志：** 平线、削波、极端振幅和线噪声，因此可以排除不良窗口
- **简单模型：** 例如，阿尔法节奏检测器和基于频段功率的平静度估计

<a id="what-affects-the-signal"></a>

## 什么影响信号

| 因素 | 效果 |
| --- | --- |
| **眨眼和眼球运动** | 前额传感器上的大尖峰 |
| **咬紧下巴、说话、皱眉** | 压倒更高频率的肌肉活动 |
| **接触不良** | 头发、皮肤干燥或松动会导致噪音或扁平通道 |
| **运动** | 电缆和传感器运动会增加缓慢的漂移和爆发 |
| **固定传感器较少** | 无法精确定位活动，某些大脑区域未被覆盖 |

将消费者头带与研究系统进行比较的研究发现，它们可以
捕捉真实的大脑信号。事件相关电位已通过
Muse恢复，并且四个 Muse 电极的执行接近 32 电极数据集
一项情绪分类任务。但信号质量因设备而异
设置：2024 年的一项比较发现 Muse S 与 a 的对齐最弱
测试设备的研究级放大器。

<a id="what-calm-and-focus-scores-can-claim"></a>

## 冷静和专注得分可以达到什么程度

“平静”或“专注”分数是由乐队构建的 **产品解释** 权力和其他投入。它不是精神状态的直接读数。

- 分数最有意义 **相对于同一个人的基线**，而不是在人与人之间进行比较。
- 它们应该带有 **质量信息** 并在信号差时被扣留。
- 一些流行的措施并不成立。例如， SDK的焦点分数故意使用 **而不是** 使用 theta/beta 比率，因为该比率不是注意力的有效衡量标准。

请参阅 [指标和分数](/cn/overview/science/metrics-and-scores)。

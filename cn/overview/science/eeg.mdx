<a id="the-principle"></a>

## 原理

神经元通过微小的电流进行通信。当一大群人一起开火时，头皮上的传感器可以捕捉到联合活动。该录音是 **脑电图（EEG）**。它由不同频率的节奏主导：

| 乐队 | 大约。范围 | 经常与 |
| --- | --- | --- |
| 达美 | 1–4赫兹 | 深度睡眠 |
| 西塔 | 4–8赫兹 | 嗜睡，一些记忆任务 |
| 阿尔法 | 8–12 赫兹 | 放松的清醒状态，尤其是闭着眼睛的时候 |
| 贝塔 | 13–30 赫兹 | 思维活跃、警觉性 |
| 伽玛 | 30+赫兹 | 快速处理；也受到肌肉活动的严重污染 |

这些关联是人群之间的倾向，而不是任何单一时刻的规则。

<a id="consumer-headbands"></a>

## 消费类头带

Elata SDK 通过网络蓝牙支持 Muse 系列：

| 设备 | EEG 频道 | 传感器位置 |
| --- | --- | --- |
| 缪斯2、缪斯S | 4 | 耳后（TP9、TP10）和额头（AF7、AF8） |
| 缪斯S（雅典娜） | 8 | 新协议上的附加通道 |

研究级系统在盖子中使用 32 至 256 个湿电极。头带在固定位置使用了一些干传感器。这使得它既舒适又实惠，但也限制了它的测量范围。

<a id="how-the-elata-sdk-processes-eeg"></a>

## Elata SDK 如何处理 EEG

`eeg-web` 使用 WebAssembly在浏览器中运行：

- **滤波和频谱：** 去除漂移和线路噪声，并计算每个窗口的频谱
- **频段功率：** 每个频段和通道的绝对功率、相对功率和对数功率
- **质量标志：** 平线、削波、极端振幅和线噪声，因此可以排除不良窗口
- **简单模型：** 例如，阿尔法节奏检测器和基于频段功率的平静度估计

<a id="what-affects-the-signal"></a>

## 什么影响信号

| 因素 | 效果 |
| --- | --- |
| **眨眼和眼球运动** | 额头传感器上有大尖刺 |
| **咬紧牙关、说话、皱眉** | 压倒更高频率的肌肉活动 |
| **接触不良** | 头发、皮肤干燥或宽松会导致噪音或扁平通道 |
| **运动** | 电缆和传感器运动增加了缓慢的漂移和爆发 |
| **少量固定传感器** | 无法精确定位活动，某些大脑区域未被覆盖 |

将消费者头带与研究系统进行比较的研究发现，它们可以捕获真实的大脑信号。事件相关电位已通过 Muse 恢​​复，并且在一项情绪分类任务中，四个 Muse 电极的表现接近 32 电极数据集。但信号质量因设备和设置而异：2024 年的一项比较发现，在测试的设备中，Muse S 与研究级放大器的一致性最弱。

<a id="what-calm-and-focus-scores-can-claim"></a>

## 冷静和专注得分可以达到什么水平

“冷静”或“专注”分数是根据频段功率和其他输入构建的 **产品解释** 。它不是精神状态的直接读数。

- 分数最有意义 **相对于同一个人的基线**，而不是在人与人之间进行比较。
- 它们应该带有 **质量信息** 并在信号较差时被保留。
- 一些流行的措施并不成立。例如，SDK 的 Focus 分数故意使用 **而不是** 使用 theta/beta 比率，因为该比率不是注意力的有效衡量标准。

请参阅 [指标和分数](/cn/overview/science/metrics-and-scores)。

<a id="what-data-exists"></a>

## 存在哪些数据

Elata 的构建使得原始生物信号不需要离开用户的设备。这决定了数据的存在：

| 数据 | 存在吗？ | 哪里 |
| --- | --- | --- |
| 原始相机帧 | Elata 的服务器管道不收集 | 本地处理 |
| 原始 EEG 和 PPG | 不被Elata的服务器管道收集；本地实验记录是可能的 | 启用兼容录制主机时用户的浏览器存储 |
| 生物识别得分的派生会话结果 | 是的，经同意 | Elata，适用于选择加入的用户 |
| 应用程序保存、记录和分数 | 是 | 用户的帐户，范围仅限于每个应用程序 |
| 聚合应用分析 | 是 | 每个应用程序的构建者都可以看到，并且是匿名的 |

<Note>
Elata 目前不提供研究数据集或数据访问程序。
</Note>

<a id="running-your-own-study"></a>

## 开展自己的研究

研究人员可以直接使用开源工具：

- **将研究构建为 Elata 应用程序。** 使用 SDK 进行捕获和处理，并将其发布到 Elata 上以通过浏览器到达参与者。您的应用程序对其自己的同意和研究协议负责。根据 Elata 的 [提交政策](/cn/apps/build/review-and-policy)，应用程序不得从设备发送原始生物信号。
- **在您自己的工具中使用SDK。** 传感器包可在 Elata 之外的任何 Web 应用程序中使用，并根据您自己机构的数据处理进行操作。

<a id="recording-sessions-experimental"></a>

## 录制会话（实验）

<Warning>
实验性的。 SDK提供录制合约。应用商店的 `feat/long-local-analytics` 分支实现了本地录制主机、会话页面和存储控制，但在生产中明确禁用它们。
</Warning>

`biosignal-session` 将多传感器会话（EEG、 PPG、 rPPG 指标等）记录为 Apache Arrow 文件中的类型化流，旨在提高可靠性：

- 每个块都带有校验和和稳定的身份，因此可以安全地存储和重试
- 真实的数据间隙会被记录为显式的不连续，绝不插值
- time 是单个会话时钟（以整数微秒为单位）

录音是本地的：该包没有网络客户端。嵌入它的应用程序决定数据的存储位置。请参阅 [生物信号会话](/cn/sdk/biosignal-session/getting-started)。

## 分析工具（实验）

`biosignal-analytics` 提供可重复的特征和透明的分数，每个值都可以追溯到生成它的算法和版本。请参阅 [指标和分数](/cn/overview/science/metrics-and-scores)。

## 我们的立场

Elata 为 **健康、游戏、学习和研究**构建工具。的
应用程序使用的信号 Elata （相机心率、消费者 EEG和头带 PPG）是
真实的生理测量，但它们来自消费设备
不受控制的设置。它们是估计值，而不是临床读数。

由此得出三个规则：

1. **无诊断。** Elata 和 Elata 应用程序不诊断、治疗或监控医疗状况。
2. **显示不确定性。** 测量值带有信号质量和置信度值，当数据不够好时，分数会自动保留，而不是猜测。
3. **对每项索赔进行评分。** 测量的心率和“焦点”得分是不同类型的声明， SDK 对它们进行了不同的标记。

## 索赔如何分级

 SDK的分析包（`biosignal-analytics`，当前
[实验性](/cn/overview/status)）为每个指标提供了一个已注册的定义
有两个标签。

**计量类：** 是什么样的数字。

| 类别 | 含义 | 示例 |
| --- | --- | --- |
| 测量值 | 直接从信号中读取或多或少 | 心率 |
| 导出（确定性） | 通过固定公式根据测量值计算 | HRV (RMSSD)，频段功率 |
| 模型推断 | 通过统计或学习模型估计 | 学习波形重建 |
| 产品组合 | 结合多种输入的产品解释 | 专注、准备 |

**证据层：** 指标的支持程度。

| 等级 | 含义 |
| --- | --- |
| Beta 默认 | 良好支持；默认显示 |
| 高级 | 支持，但适用于知情用户 |
| 实验性 | 早期；可能会更改或删除 |
| 已拒绝 | 已评估并故意不使用 |

每个值还记录了生成它的确切算法和版本，因此
当算法改进时，它可以被追踪和重新计算。特征代码是
根据参考实现（NumPy/SciPy）进行测试，因此数字一致
跨 Rust、 WebAssembly和 JavaScript 版本。

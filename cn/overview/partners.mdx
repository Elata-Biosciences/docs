<a id="elata-today"></a>

今天## Elata 

Elata 现在有两件事：

- **[Elata](/cn/overview/apps-on-elata)**，app.elata.bio 上的一个市场，构建者在此发布生物信号应用程序，用户在浏览器中播放它们
- ** [Elata SDK](/cn/overview/elata-sdk)**，用于网络摄像头心率的开源浏览器软件包， EEG 头带和头带 PPG

有些功能是实验性的，有些是计划中的。
[实时内容](/cn/overview/status) 页面列出了每个功能及其状态，因此
你可以准确地看到今天存在的东西。

<a id="ways-to-work-with-elata"></a>

## 与 Elata合作的方式

| 你是 | 从这里开始 | 它看起来像 |
| --- | --- | --- |
| **设备制造商** | [设备集成](/cn/integrate) | 实施 SDK的运输合同，以便您的耳机适用于每个 Elata 应用程序 |
| **研究人员** | [科学](/cn/overview/science/overview) | 将研究构建为 Elata 应用程序，或在您自己的工具中使用开源 SDK  |
| **应用程序工作室或开发人员** | [构建应用程序](/cn/apps/what-are-elata-apps) | 发布于 Elata 并使用其内置帐户和支付 |
| **投资者或生态系统合作伙伴** | [ Elata 如何组合在一起](/cn/overview/ecosystem-map) | 了解组件，然后联系 |

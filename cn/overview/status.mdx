## Elata SDK

仓库中的 API 与已发布软件包可能不同。使用仅源码提供的 API 前，检查已安装版本和发行说明；以下发布状态并不保证 npm 版本包含当前源码中的每项功能。

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| `rppg-web`、`eeg-web`、`eeg-web-ble`、`ppg-web` | 已上线 | 已发布到 npm。[SDK 概览](/cn/sdk/overview) |
| `app-metrics`、`app-payments` | 已上线 | 已发布到 npm |
| `create-elata-demo`（入门应用） | 仓库版本 0.12.1 存在打包阻碍 | 缺少 `app-metrics` 版本元数据，打包后的 CLI 无法启动。使用前确认修复版本。 |
| `app-state` | 实验性 | 尚未发布到 npm。应用可以直接使用 [`elata:state:*` 消息](/cn/apps/platform/app-state)。 |
| `biosignal-session`、`biosignal-analytics`、`rppg-models-web` | 实验性 | 仅源码，尚未发布到 npm；API 可能变化。 |
| 通过 Web Bluetooth 使用 Muse 2、Muse S、Muse S（Athena） | 已上线 | Chrome 或 Edge。[设备](/cn/users/devices) |
| 使用网络摄像头进行 rPPG | 已上线 | |

## 从当前产品退役的功能

<a id="what-an-elata-app-is"></a>

## 什么是 Elata 应用

Elata 应用是响应身体信号的 Web 应用，例如摄像头检测的脉搏、EEG 头带读取的脑活动，或头带光学传感器测得的心率。你在 [app.elata.bio](https://app.elata.bio) 打开应用，直接在浏览器中使用，无需安装。

---

<a id="kinds-of-apps"></a>

## 应用类型

| 类别 | 示例 |
| --- | --- |
| **游戏** | 响应心率、专注或平静程度的游戏 |
| **神经指标** | 实时 EEG 和心率仪表盘 |
| **健康生活** | 呼吸练习、冥想和恢复 |
| **工具** | 专注计时器和个人追踪 |
| **实验** | 研究、原型和科研应用 |

<a id="how-apps-get-onto-elata"></a>

## 应用如何进入 Elata

任何人都可以使用开源 [Elata SDK](/cn/overview/elata-sdk) 构建应用。发布时，开发者先注册应用，再上传构建产物并提交审核。

每个版本都要经过：

1. **上传自动检查**：文件布局、大小限制和 Elata SDK 使用情况。
2. **自动代码安全扫描**。
3. **人工审核**，检查是否符合[提交政策](/cn/apps/build/review-and-policy)。

只有获批版本才对公众开放。开发者可以在获批前将草稿分享给少量测试者。

<a id="how-apps-run-safely"></a>

## 应用如何安全运行

每个应用都在独立 Web 来源上的**隔离沙箱**中运行，因此：

- Elata 桥接不会向嵌入应用披露账户邮箱、钱包密钥或会话令牌；公开活动和付款记录仍可能识别用户。
- 应用可以请求摄像头或 Bluetooth，但浏览器会先征求你的许可。
- 应用需要购买、保存进度等平台能力时，会发出请求，由 Elata 代表你处理。
- 付款详情不会通过应用。

<a id="what-builders-get"></a>

## 开发者获得什么

开发者无需自建账户、支付、托管和存储系统。Elata 提供：

| 功能 | 状态 |
| --- | --- |
| 托管、应用页面、评价和发现 | 已上线 |
| 每位用户的进度和分数保存 | 已上线 |
| Elata 代发提醒 | 已上线 |
| 贡献到用户自愿启用的生物特征评分 | 已上线 |
| 一次性应用内购买 | 已在 IAP 更新分支实现；需验证部署和付款配置 |
| 月度订阅 | 实验性 |

详情见[当前可用功能](/cn/overview/status)，开始开发请阅读[构建应用](/cn/apps/what-are-elata-apps)标签。

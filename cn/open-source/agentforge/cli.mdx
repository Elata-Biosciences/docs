## 安装

安装软件包后，CLI 可作为 `forge-sim` （或 `agentforge`）使用：

```bash
pnpm add @elata-biosciences/agentforge
```

<a id="commands"></a>

## 命令

### `forge-sim init [path]`

搭建一个包含示例场景和配置的模拟文件夹。

```bash
forge-sim init                    # Initialize in current directory
forge-sim init sim/               # Initialize in sim/ subdirectory
```

### `forge-sim run <scenario>`

执行场景文件并生成工件。

```bash
forge-sim run sim/scenarios/stress.ts
forge-sim run --toy                          # Run built-in demo scenario
```

**选项：**

| 旗帜 | 说明 |
|------|-------------|
| `--seed <n>` | 覆盖随机种子 |
| `--ticks <n>` | 覆盖刻度计数 |
| `--out <dir>` | 工件的输出目录 |
| `--mode <mode>` | `deterministic` （默认）、 `exploration`或 `replay` |
| `--replay-bundle <path>` | 重播捆绑包路径（对于 `--mode replay`） |
| `--capture-memory` | 持久化代理内存快照 |
| `--live` | 启用实时 WebSocket 事件流 |
| `--ci` | CI模式——无颜色，命名稳定 |
| `--verbose` | 详细日志记录 |
| `--json` | 将结果输出为 JSON |

**模式指导：**
- **`deterministic`** — 没有现场 LLM 电话；最适合基线和 CI
- **`exploration`** — 支持 LLM 的红队发现；生产 `replay_bundle.json`
- **`replay`** — 先前探索轨迹的确定性重新运行

### `forge-sim studio`

启动 Studio 仪表板进行多次运行分析。

```bash
forge-sim studio
```

### `forge-sim report <runDir>`

从运行工件生成 Markdown 报告。

```bash
forge-sim report results/market-stress-ci/
```

### `forge-sim dashboard <runDir>`

从运行工件构建静态 HTML 仪表板。

```bash
forge-sim dashboard results/market-stress-ci/
```

### `forge-sim serve <runDir>`

通过 HTTP 提供运行仪表板。

```bash
forge-sim serve results/market-stress-ci/
```

### `forge-sim compare <runA> <runB>`

比较两次运行 - 比较指标、操作和工件哈希。

```bash
forge-sim compare results/run1 results/run2
```

### `forge-sim sweep <scenario>`

多种子统计分析。在一系列种子中运行相同的场景并聚合结果。

```bash
forge-sim sweep sim/scenarios/stress.ts --seeds 1..50
```

### `forge-sim matrix <scenario>`

多变量矩阵比较。运行多个参数组合并生成比较矩阵。

```bash
forge-sim matrix sim/scenarios/stress.ts
```

### `forge-sim extract-agent <bundle>`

从重播包生成确定性代理。对于将 LLM 探索痕迹转换为可重现的测试代理很有用。

```bash
forge-sim extract-agent results/run/replay_bundle.json
```

### `forge-sim doctor`

检查所有依赖项（Node.js、Foundry、Anvil）是否可用且配置正确。

```bash
forge-sim doctor
```

### `forge-sim types`

从 Foundry 工件生成 TypeScript 类型。

```bash
forge-sim types
```

## 持续集成集成

AgentForge 专为 CI 管道而设计。退出代码：

| 错误代码 | 含义 |
|------|---------|
| `0` | 所有断言均通过 |
| `1` | 一个或多个断言失败 |
| `2` | 基础设施错误 |

GitHub Actions 工作流程示例：

```yaml
- name: Run simulations
  run: npx forge-sim run sim/scenarios/stress.ts --ci --seed 42

- name: Upload artifacts
  uses: actions/upload-artifact@v4
  if: always()
  with:
    name: simulation-results
    path: sim/results/
```

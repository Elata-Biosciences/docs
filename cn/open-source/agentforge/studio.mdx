## 概述

AgentForge Studio 是一个受彭博终端启发的仪表板，用于分析模拟运行。启动它：

```bash
forge-sim studio
```

---

<a id="dashboard-tabs"></a>

## 仪表板选项卡

<a id="session-management"></a>

### 会话管理

浏览所有模拟运行、构建或打开仪表板以及下载工件。每次运行均由其场景名称、种子和时间戳来标识。

<a id="financial-charts"></a>

### 金融图表

由轻量级图表提供支持的交互式时间序列图表：

- 价格、数量和自定义指标可视化
- 缩放、平移和十字准线工具提示
- 用于相关性分析的多指标叠加

<a id="timeline-inspector"></a>

### 时间线检查员

虚拟化操作日志显示所有代理的所有操作：

- 按代理、操作类型或刻度范围过滤
- 用于操作参数和结果的 JSON 检查弹出窗口
- 按操作结果（成功/失败）进行颜色编码

<a id="gossip-analysis"></a>

### 八卦分析

通道级消息流可视化：

- 每个通道的消息量和时间
- 作者跟踪和交付状态
- 可信度分数分布
- 策略通道隔离视图

<a id="agent-stats"></a>

### 代理统计

每个代理的绩效细分：

- 行动次数和成功率
- 收入/损益跟踪（如适用）
- 深入了解个人代理历史记录

<a id="ml-toolkit"></a>

### 机器学习工具包

服务器端统计分析工具：

- **回归** — 将模型拟合到公制时间序列
- **PCA** — 代理行为的降维
- **K-means 聚类** — 按行为模式对运行或代理进行分组
- **交叉运行比较** — 来自多个种子或变体的叠加指标

<a id="report"></a>

### 报告

自动生成的 Markdown 报告包含：

- 运行摘要和配置
- 关键指标亮点
- 断言结果
- 值得注意的代理人行为

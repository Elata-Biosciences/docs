---
title: "快速入门"
description: "构建一个生物信号应用程序并将其发布到 Elata。"
---

本指南将带您从一无所有到提交应用程序。您需要 Node.js 20 或
较新的和网络摄像头。

<Warning>
  **已知问题：** 存储库的 `create-elata-demo` 0.12.1 具有打包阻止程序，并且在没有同级工作区元数据的情况下无法启动。在使用之前验证固定版本。现在，按照
  [添加 rPPG 到现有应用程序](/cn/sdk/tutorials/rppg-existing-app) 进行设置
  而是在您自己的网络应用程序中使用 SDK 。请参阅 [直播内容](/cn/overview/status)。
</Warning>

<Steps>
  <Step title="搭建一个应用程序支架">
创建相机心率 (rPPG) 入门应用：

    ```bash
    npm create @elata-biosciences/elata-demo my-app -- --template rppg
    cd my-app
    npm install
    ```

喜欢 EEG、头带 PPG，还是游戏？参见 [模板列表](/cn/sdk/create-elata-demo)。
  </Step>

  <Step title="本地运行">
    ```bash
    npm run dev
    ```

打开本地 URL，允许摄像头访问，您应该会看到实时脉冲信号。
  </Step>

  <Step title="让它成为你的">
在 `src/`中编辑应用程序。 [rPPG 指南](/cn/sdk/guides/rppg-browser) 解释了会话 API，以及 [平台 API](/cn/apps/platform/host-bridge) 添加购买、保存的进度和分数。
  </Step>

  <Step title="添加版本">
创建 `public/elata.json`：

    ```json
    { "version": "1.0.0" }
    ```

请参阅 [elata.json](/cn/apps/build/elata-json)。
  </Step>

  <Step title="构建上传">
    ```bash
    npm run build:zip
    ```

这会在根处写入 `app.zip` 和 `index.html` 。
  </Step>

  <Step title="发布">
前往 [app.elata.bio/build-app](https://app.elata.bio/build-app)，注册您的应用名称，上传 `app.zip`，在播放窗口中尝试，添加图标和标题图片，然后提交审核。完整的演练位于 [发布您的应用程序](/cn/apps/build/launch-your-app)。
  </Step>
</Steps>

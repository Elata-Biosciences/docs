## 页面字段

你可以在向导的“发布”步骤中填写这些字段，之后随时可在应用的**编辑**页面修改。

| 字段 | 提交时必填 | 限制 |
| --- | --- | --- |
| 名称 | 是 | 最多 50 个字符，注册时设置。 |
| 应用图标 | 是 | 正方形图片 |
| 头图 | 是 | 显示在应用页面顶部的宽幅横幅 |
| 描述 | 建议 | 10 到 1,000 个字符，显示在商店卡片上。 |
| 详细描述 | 否 | 最多 5,000 个字符，显示在应用页面上。 |
| 类别 | 是 | Games、Neurometrics、Wellness、Tools 或 Experiments |
| 标签 | 否 | 最多 5 个标签，每个最多 30 个字符 |
| 截图 | 否 | 最多 10 张 |
| 社交链接 | 否 | 网站、X/Twitter、Discord、GitHub、Telegram、Farcaster、YouTube 等，另可添加最多 5 个自定义链接 |
| 团队 | 否 | 显示在应用页面上的团队成员 |

<Note>
  提交版本时，商店页面信息会被固定到该版本上。之后的修改将用于你的下一个版本。
</Note>

## 图片规范

| 素材 | 推荐尺寸 | 格式 |
| --- | --- | --- |
| 应用图标 | 512×512 px | PNG、JPG、WebP |
| 头图 | 1920×600 px | PNG、JPG、WebP |
| 桌面截图 | 1920×1080 px（16:9） | PNG、JPG、WebP |
| 移动端截图 | 1080×1920 px（9:16） | PNG、JPG、WebP |

每张上传的图片限制为 5 MB。

<Tip>
  当你的包没有自带 Web 清单时，你的图标也会用于添加到主屏幕。请使用在小尺寸下也清晰可辨的正方形图标。
</Tip>

## 应用的 URL

| URL | 说明 |
| --- | --- |
| `app.elata.bio/app/<slug>` | 你的商店页面 |
| `app.elata.bio/app/<slug>/play` | 用户使用你应用的地方 |
| `app.elata.bio/app/<slug>.md` | 商店页面的纯文本 Markdown 版本，便于分享给 AI 工具 |

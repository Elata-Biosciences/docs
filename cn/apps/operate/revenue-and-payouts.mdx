应用直接销售收入在分账合约扣除配置的平台费用后，发送到应用的收款钱包。你通过该钱包转移资金；Elata 不另设等待提现的开发者余额。

<a id="open-your-commerce-dashboard"></a>

## 打开 Commerce 仪表盘

打开 **My Apps → 你的应用 → Edit → Commerce**，对应应用商店中的 `/app/<slug>/edit#commerce`。

| 面板 | 内容 |
| --- | --- |
| Products | 商品目录和启用状态 |
| Monthly subscription | 应用价格、试用设置、启用状态和订阅人数信号 |
| Revenue | 商品销量、估算商品收入、已记录的订阅付款和估算总收入 |
| Transactions | 近期商品和订阅记录，以及可用的交易链接 |
| Funds | 收款地址及其在 Base 上的当前 USDC 余额 |

<a id="understand-the-numbers"></a>

## 理解这些数字

**商品收入是估算值。** 购买记录不保存历史实付金额。报告将购买次数乘以商品当前价格；修改价格会改变历史销售的估算值，但不会改变用户实际付出的金额。

**订阅收入使用已记录金额。** 已付费期间保存付款时的金额。免费试用不属于付费订阅收入。

**Revenue 显示的是总收入。** 报告不计算扣除平台费用后的准确净收入。如果提示来源记录受到数量限制，总计也可能不完整。请用交易记录核对实际付款和收款金额。

**Funds 显示钱包余额。** 它包含该钱包的其他 USDC 入账，不包含已转出的资金。多个应用可以共用一个钱包；余额为零不代表应用从未获得收入。

<a id="where-payouts-go"></a>

## 收入发送到哪里

当前付款目的地是应用创建者的钱包，在 **Funds** 中显示为收款钱包。商品和月度计划没有各自独立的可编辑收款地址。

销售前，请将显示的地址与自己控制的钱包核对。如果地址错误或无法访问，请先联系[支持](/cn/users/help)。添加团队成员不会转移所有权，也不会配置自动收入分成。

<a id="access-your-funds"></a>

## 访问资金

<Steps>
  <Step title="打开 Funds">
    在 **Commerce** 中找到 **Funds**，核对完整地址并查看 **USDC balance (Base)**。余额加载失败时请刷新或重试。
  </Step>
  <Step title="使用收款钱包">
    以应用所有者身份登录，连接与收款地址对应的钱包。只有通过所有者和钱包检查时才显示 **Manage funds**。团队成员可以查看报告，但不能使用此所有者专属操作。
  </Step>
  <Step title="打开 Manage funds">
    这会打开钱包控制界面。发送、接收和导出功能取决于钱包类型。转账前，请再次核对钱包界面中的地址与收款地址。
  </Step>
</Steps>

仪表盘权限只控制它自己的按钮。独立控制收款钱包的人，也可以在 Elata 之外管理该钱包。

<a id="send-usdc-to-another-wallet"></a>

## 向其他钱包发送 USDC

1. 使用 **Manage funds** 或钱包自己的应用打开收款钱包。
2. 选择 **Base 上的 USDC** 和发送操作。
3. 输入目标地址和金额，确认目标支持 Base 上的 USDC。
4. 检查网络手续费或费用代付说明，并确认转账。
5. 保存交易哈希，确认后检查目标余额。

外部钱包可能需要 Base 上的 ETH 支付网络手续费。内嵌或智能钱包的费用处理可能不同，请以钱包显示的信息为准。导出功能在可用时导出的是钱包访问权限，不会把 USDC 换成现金。

<a id="get-money-into-a-bank-account"></a>

## 转入银行账户

Elata 的 Funds 面板不提供银行提现，也不把 USDC 换成法币。需要变现时：

1. 选择对你开放、明确接受 **Base 上的 USDC 充值**并支持银行提现的交易所或服务。
2. 在该服务中选择 **Base** 充值网络，取得 USDC 充值地址。
3. 从收款钱包向该地址发送 USDC。
4. 充值到账后，按照该服务的兑换和银行提现流程操作。

发送前检查该服务的当前最低充值额、费用、身份验证要求和银行提现选项。只有其他网络的地址是不够的。这些操作由接收服务提供，在 Elata 之外进行。

<a id="pay-collaborators"></a>

## 向合作者付款

团队权限允许合作者帮助管理应用，但不会自动分配直接销售收入。当前流程将创建者份额发送到一个收款钱包。如需支付合作者，请按照自己的协议，从该钱包转账。

<a id="troubleshooting"></a>

## 故障处理

| 问题 | 检查内容 |
| --- | --- |
| 没有 Manage funds | 所有者身份、钱包连接和显示的收款地址 |
| 打开的钱包地址不同 | 关闭界面，选中真实收款钱包后再发送 |
| 余额与 Revenue 不一致 | 总收入与净收入、商品价格估算、已转出资金、其他充值和共享钱包 |
| 客户付款未出现在报告中 | 结算和记录状态；将交易哈希与应用记录核对 |
| 余额无法加载 | 重试查询；读取失败不代表资金消失 |
| 需要更改收款地址 | 联系支持；商品和计划设置不会更改付款目的地 |

付款缺失或有争议时，请保留应用标识、日期、商品或付费期间和交易哈希，通过[帮助](/cn/users/help)联系支持。仪表盘不提供自助退款、替换收款地址或直接银行提现按钮。

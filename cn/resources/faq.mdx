## 概况

<AccordionGroup>
  <Accordion title="什么是 Elata？">
    一个用于构建和分发生物信号应用的平台：包括用于 rPPG、EEG 和 PPG 的浏览器 SDK，以及发布和使用这些应用的 [Elata 应用商店](https://app.elata.bio)。参见[什么是 Elata？](/cn/learn/protocol-overview)。
  </Accordion>
  <Accordion title="我需要特殊硬件吗？">
    不需要。摄像头（rPPG）应用适用于任何网络摄像头。EEG 和头带 PPG 应用需要 Muse 等受支持的头带。
  </Accordion>
  <Accordion title="支持哪些浏览器？">
    摄像头应用可在现代浏览器中运行。蓝牙 EEG 需要支持 Web Bluetooth 的 Chromium 内核浏览器（桌面和 Android 上的 Chrome 或 Edge）。参见[兼容性](/cn/sdk/operations/compatibility)。
  </Accordion>
</AccordionGroup>

## 开发应用

<AccordionGroup>
  <Accordion title="如何发布应用？">
    使用 SDK 构建 Web 应用，然后通过 [app.elata.bio/build-app](https://app.elata.bio/build-app) 的“构建应用”向导发布。参见[快速开始](/cn/quickstart)。
  </Accordion>
  <Accordion title="我的应用必须使用 SDK 吗？">
    是的。上传的应用必须至少使用一个 Elata 传感器 SDK（rPPG、EEG 或 PPG）。参见[要求](/cn/apps/build/requirements)。
  </Accordion>
  <Accordion title="发布需要多少费用？">
    一笔以 USDC 支付的少量一次性注册费，金额会在向导中显示。
  </Accordion>
  <Accordion title="我的应用如何赚钱？">
    通过[应用内购买](/cn/apps/platform/in-app-purchases)出售一次性物品，或收取月度[订阅](/cn/apps/platform/subscriptions)费用。
  </Accordion>
  <Accordion title="我可以自行托管应用吗？">
    可以，但需要审批。在应用的编辑页面申请外部托管。参见[上传与托管](/cn/apps/build/upload-and-hosting)。
  </Accordion>
  <Accordion title="审核需要多长时间？">
    每个版本都会先经过自动扫描，再由审核员审核。获批后你会在商店内和邮件中收到通知。
  </Accordion>
</AccordionGroup>

## 隐私

<AccordionGroup>
  <Accordion title="我的摄像头或 EEG 数据会离开我的设备吗？">
    原始信号在你的设备上处理，应用不得将其发送到任何地方。参见[隐私与数据](/cn/learn/privacy-and-data)。
  </Accordion>
  <Accordion title="什么是生物特征评分？">
    一个可选的跨应用指标，由派生的会话结果构成。只有在你同意后才会生成，你也可以随时关闭。
  </Accordion>
</AccordionGroup>

## 账户与积分

<AccordionGroup>
  <Accordion title="我需要加密钱包吗？">
    不需要。你可以使用社交账号登录，连接已有钱包是可选的。
  </Accordion>
  <Accordion title="什么是 Elata 积分？">
    参与商店活动获得的不可转让积分。参见 [Elata 积分](/cn/elata-points)。
  </Accordion>
</AccordionGroup>

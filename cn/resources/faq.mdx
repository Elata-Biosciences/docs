<a id="about-elata"></a>

## 关于艾拉塔

<AccordionGroup>
  <Accordion title="Elata是什么？">
尊重隐私的生物信号应用程序市场，位于 [app.elata.bio](https://app.elata.bio)，以及用于构建这些应用程序的开源 Elata SDK。请参阅 [欢迎](/cn/overview/welcome)。
  </Accordion>
  <Accordion title="Elata 是医疗产品吗？">
不会。Elata 应用程序适用于健康、游戏、学习和研究。他们不诊断、治疗或监测任何医疗状况。请参阅 [安全和限制](/cn/users/safety-and-limitations)。
  </Accordion>
  <Accordion title="什么's available today?">
 [实时功能](/cn/overview/status) 页面列出了每个功能的实时状态、实验状态、计划状态或退役状态。
  </Accordion>
</AccordionGroup>

<a id="using-apps"></a>

## 使用应用程序

<AccordionGroup>
  <Accordion title="我需要特殊的硬件吗？">
不会。相机应用程序适用于任何网络摄像头。 EEG 和头带心率应用程序需要受支持的头带，例如 Muse。请参阅 [设备](/cn/users/devices)。
  </Accordion>
  <Accordion title="支持哪些浏览器？">
相机应用程序可以在现代浏览器中运行。蓝牙头带需要Chrome或Edge（网页蓝牙）； Safari 和 iOS 浏览器不支持。请参阅 [设备](/cn/users/devices)。
  </Accordion>
  <Accordion title="我需要一个加密钱包吗？">
不需要。您可以使用社交登录名进行登录。连接现有钱包是可选的。
  </Accordion>
  <Accordion title="需要花费什么吗？">
浏览和玩都是免费的。有些应用程序出售可选项目或提供按月订阅。请参阅 [货币化](/cn/overview/monetization)。
  </Accordion>
</AccordionGroup>

<a id="privacy"></a>

## 隐私

<AccordionGroup>
  <Accordion title="我的相机或 EEG 数据会离开我的设备吗？">
原始信号在您的设备上进行处理，并且应用程序不允许将它们发送到任何地方。请参阅 [隐私和同意](/cn/overview/privacy-and-consent)。
  </Accordion>
  <Accordion title="什么是生物识别分数？">
根据派生会话结果构建的可选跨应用度量。它仅在您选择加入时才会构建，并且您可以随时将其关闭。请参阅 [分数和见解](/cn/users/score-and-insights)。
  </Accordion>
  <Accordion title="如何删除我的数据？">
电子邮件 [info@elata.bio](mailto:info@elata.bio)。请参阅 [您的数据](/cn/users/your-data)。
  </Accordion>
</AccordionGroup>

<a id="building-apps"></a>

## 构建应用程序

<AccordionGroup>
  <Accordion title="如何发布应用程序？">
使用 Elata SDK 构建 Web 应用程序，然后使用位于 [app.elata.bio/build-app](https://app.elata.bio/build-app)的构建应用程序向导。请参阅 [快速入门](/cn/apps/quickstart)。
  </Accordion>
  <Accordion title="我的应用程序必须使用 Elata SDK 吗？">
是的。上传必须至少使用一个 Elata 传感器包（rPPG、 EEG或 PPG）。请参阅 [要求](/cn/apps/build/requirements)。
  </Accordion>
  <Accordion title="出版要花多少钱？">
一次性注册费 USDC，如向导所示。
  </Accordion>
  <Accordion title="我如何从我的应用程序中赚钱？">
出售一次性物品或收取每月订阅费。请参阅 [通过您的应用获利](/cn/apps/build/monetize)。
  </Accordion>
  <Accordion title="审核需要多长时间？">
每个版本都会自动扫描，然后由主持人审核。批准后，您会在 Elata 上收到通知并通过电子邮件收到通知。
  </Accordion>
</AccordionGroup>

<a id="points-and-the-token"></a>

## 积分和代币

<AccordionGroup>
  <Accordion title="什么是 Elata 积分？">
您通过参与游戏、评论、建造和邀请朋友赚取链下积分。它们不能被购买、出售或转让。请参阅 [Elata 积分](/cn/overview/points)。
  </Accordion>
  <Accordion title="我需要 ELTA 才能使用Elata吗？">
否。参见 [ELTA 代币](/cn/overview/elta-token)。
  </Accordion>
  <Accordion title="哪里可以买到 ELTA？">
目前尚无官方流动性池。任何在官方公告之前出现的矿池均未经授权。请参阅 [ELTA 代币](/cn/overview/elta-token)。
  </Accordion>
</AccordionGroup>

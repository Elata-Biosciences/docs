部分应用提供一次性商品或按月付费访问。Elata 处理结账，并在您的账户中保存购买和访问记录。

<Info>
付费功能需要部署完成相关配置后才能使用。请查看[当前状态](/cn/overview/status)及结账界面显示的网络。本流程中的应用内商品和应用订阅使用 Base 网络上的 USDC；其他网络的测试网资金不能用于付款。
</Info>

<a id="find-your-billing-settings"></a>

## 找到账单设置

打开[设置 → 账单](https://app.elata.bio/settings/billing)。

| 页面 | 可以做什么 |
| --- | --- |
| [购买](https://app.elata.bio/settings/billing/purchases) | 查看已拥有的应用内商品，并返回对应应用 |
| [订阅](https://app.elata.bio/settings/billing/subscriptions) | 查看应用访问权限，选择需要付费的月份 |
| [历史](https://app.elata.bio/settings/billing/history) | 查看商品、订阅及使用额度的付款记录 |
| [钱包](https://app.elata.bio/settings/billing/wallet) | 查看账户钱包、当前连接的钱包及使用额度余额 |

<a id="buy-an-in-app-item"></a>

## 购买应用内商品

<Steps>
  <Step title="登录并选择商品">
打开应用提供的购买入口或应用内商店，确认商品描述和价格。一次性商品在购买账户上永久解锁，并非每次使用都会消耗的商品。
  </Step>
  <Step title="完成 Elata 结账">
连接或打开结账界面要求的钱包。支付钱包需要有足够的 Base 网络 USDC。确认所请求的付款操作，等待交易结算并记录。
  </Step>
  <Step title="使用已购买的商品">
Elata 确认成功后，应用会解锁相应内容。您可以在 **账单 → 购买** 中再次找到商品；使用同一账户返回应用即可恢复购买。
  </Step>
</Steps>

已拥有的商品应显示“已拥有”，无需再次付款。如果相应权益未显示，请先使用购买账户重新打开应用并检查购买记录，再尝试重新结账。

<a id="subscribe-to-an-app"></a>

## 订阅应用

启用月度计划的应用会在详情页或受限的使用页面显示价格及可用试用。符合条件的免费试用无需付款；付费访问在 **账单 → 订阅** 中管理。

1. 如果应用支持内嵌结账，使用其订阅提示；也可以打开 **订阅** 管理购物车。
2. 选择提供的月份：当月、下个月，或两者（如可用）。
3. 检查购物车中的访问起止日期与总价。多个应用可以一起付款。
4. 完成结账，等待所选月份显示为已付款。

应用订阅按 **UTC 日历月** 计算，而不是从购买日开始计算 30 天。下个月的访问从该月第一天开始。如果提供当月访问，购物车会显示访问范围和按比例计算的价格。

<a id="renew-or-stop-renewing"></a>

### 续订或停止续订

应用订阅**不会自动扣款**。选择下个月的应用只是将其加入购物车，仍需完成付款。

要停止续订，保持下个月未付款即可。取消勾选未付款的选项会将其从购物车移除，但不会取消或退还已经购买的月份。访问权限持续到已付款期限或试用结束日期，之后到期，除非您拥有其他形式的访问权限。

<a id="google-sign-in-wallets-and-credits"></a>

## Google 登录、钱包和使用额度

登录用于识别您的 Elata 账户。完成付款需要一个可以授权交易的活跃钱包。Google 或邮箱登录可以使用嵌入式钱包；当前结账流程会尝试自动恢复它，因此您无需外部加密钱包即可登录或开始结账。您仍可能需要向钱包添加 Base 网络 USDC。如果账户钱包无法恢复，请按照恢复或连接提示操作。付款确认在钱包界面中完成。

**账单 → 钱包** 同时显示账户钱包与当前连接的钱包。如果两者不同，请在付款前确认账户与钱包。仅连接钱包并不保证其他付款方能够通过您的账户验证。

使用额度（credits）用于受支持的按量计费功能。充值使用额度不会增加钱包的 USDC 余额，也不会自动支付应用内商品或应用订阅。[Elata 积分](/cn/overview/points)是另一套独立的参与系统。

<a id="payment-problems-and-history"></a>

## 付款问题与历史记录

| 状态 | 操作 |
| --- | --- |
| 未登录 | 登录应拥有该购买的账户 |
| 正在恢复账户钱包 | 等待嵌入式钱包恢复；失败时按提示恢复 |
| 没有可用的支付钱包 | 按照结账界面的钱包连接提示操作 |
| 余额不足 | 向支付钱包添加 Base 网络 USDC，然后重试 |
| 等待确认或记录 | 保持结账界面打开，直到完成 |
| 交易已结算但访问权限缺失 | 保存交易哈希，检查历史与访问权限，再次付款前联系支持 |
| 结账不可用 | 部署可能尚未配置付款；稍后查看或联系支持 |

历史页面提供付款记录，不是退款或发票门户。标有 **≈** 的商品金额按当前价格估算；实际支付金额以交易记录为准。历史记录数量有限时，可能只显示近期记录。

账单问题请通过[帮助](/cn/users/help)联系支持，并提供应用、商品或月份、购买账户、交易哈希（如有）及显示的错误。不要分享钱包密钥或助记词。这些设置不提供自助退款流程。

<a id="common-fixes"></a>

## 常见修复

| 问题 | 尝试一下 |
| --- | --- |
| 相机应用程序没有显示脉搏 | 面向光源，静坐，检查浏览器是否有拍照权限 |
| 头带无法连接 | 使用 Chrome 或 Edge，打开蓝牙，为头带充电，然后从应用内配对 |
| “不支持蓝牙” | Safari 和 iOS 浏览器不支持网络蓝牙；使用装有 Chrome 或 Edge 的桌面或 Android 设备 |
| 读数跳跃 | 请参阅 [设备](/cn/users/devices)上的佩戴和照明提示 |
| 我的进度不见了 | 确保您登录到同一个帐户；每个帐户都会保存进度 |
| 购买未解锁 | 重新加载应用程序。如果仍处于锁定状态，请联系支持人员并提供应用程序名称和购买时间 |

<a id="get-support"></a>

## 获得支持

- **反馈按钮：** 使用 [app.elata.bio](https://app.elata.bio)上的反馈按钮。许多应用程序也从自己的菜单中打开它。
- **Discord：** 在 [Discord](https://discord.gg/yGxZpswpjS)上询问社区和团队。
- **邮箱：** [info@elata.bio](mailto:info@elata.bio)

---

<a id="report-an-app"></a>

## 举报应用程序

如果应用程序损坏、误导、不安全或违反 [提交政策](/cn/apps/build/review-and-policy)，请通过反馈按钮或将应用程序的名称和发生的情况发送至 [info@elata.bio](mailto:info@elata.bio)。 Elata 上的每个应用程序在发布前都会经过审核，报告有助于保持这种状态。

---

<a id="security-issues"></a>

## 安全问题

如果您发现 Elata 本身存在安全问题，请私下向 [info@elata.bio](mailto:info@elata.bio) 报告，而不是公开发布。

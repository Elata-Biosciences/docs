<a id="common-fixes"></a>

## 常见修复

| 问题 | 尝试 |
| --- | --- |
| 相机应用无脉搏 | 面向光源，静坐，检查浏览器是否有相机权限 |
| 头带无法连接 | 使用 Chrome 或 Edge，打开蓝牙，为头带充电，然后从应用程序内部配对 |
| “不支持蓝牙” | Safari 且iOS浏览器不支持 Web Bluetooth；使用带有 Chrome 或 Edge |的桌面或 Android 设备
| 读数跳跃 | 请参阅 [设备上的安装和照明提示](/cn/users/devices) |
| 我的进度缺失 | 确保您登录的是同一个帐户；每个帐户保存进度 |
| 购买未解锁 | 重新加载应用程序。如果仍处于锁定状态，请联系支持人员并提供应用程序名称和购买时间 |

<a id="get-support"></a>

## 获得支持

- **反馈按钮：** 使用 [app.elata.bio](https://app.elata.bio)上的反馈按钮。许多应用程序也从自己的菜单中打开它。
- **Discord：** 在 [Discord](https://discord.gg/yGxZpswpjS)上询问社区和团队。
- **电子邮件：** [info@elata.bio](mailto:info@elata.bio)

---

<a id="report-an-app"></a>

## 举报应用程序

如果应用程序损坏、误导、不安全或违反
[提交政策](/cn/apps/build/review-and-policy)，请发送应用程序的名称和内容
通过反馈按钮或发送至
[info@elata.bio](mailto:info@elata.bio)发生。 Elata 上的每个应用程序都经过审核
发布，报告有助于保持这种状态。

---

<a id="security-issues"></a>

## 安全问题

如果您发现 Elata 本身存在安全问题，请私下向
[info@elata.bio](mailto:info@elata.bio) 报告，而不是公开发布。

<a id="the-short-version"></a>

## 简短版本

- **原始信号保留在您的设备上。** 相机视频、原始 EEG和原始心脏信号在您的浏览器中进行处理。
- **Elata 的桥扣留帐户凭据。** 沙盒应用程序不会通过它接收您的电子邮件、钱包密钥或会话令牌。公共活动、商业记录和您输入的信息仍然可以识别您的身份。
- **生物识别得分贡献是可选择的。** 此同意与应用程序保存、记录、分数、使用信息和付款的云存储分开。
- **您可以随时要求索取您的数据或删除数据** 。

<a id="whats-kept-and-where"></a>

## 保存什么以及保存在哪里

| 什么 | 哪里 | 谁能看到它 |
| --- | --- | --- |
| 原始相机帧 | 本地处理； Elata 的服务器管道不收集 | 本地处理应用程序 |
| 原始生物信号 | 本地处理；兼容的实验应用程序可以保留本地会话录音 | 您和本地记录/分析软件 |
| 保存、设置应用程序商店并对其进行评分 | 您的 Elata 帐户，每个应用程序单独使用 | 仅您和该应用程序 |
| 您的分数的派生结果（如果您选择加入） | Elata | 你；您允许的应用程序可以读取您自己的见解 |
| 您的个人资料、评论和评论 | Elata | 公开，就像在任何社区网站上一样 |
| 使用情况分析 | Elata | Elata；构建者可以看到他们的应用程序的聚合，并进行小队列抑制 |
| 购买和订阅记录 | Elata 和支付网络 | 您、Elata 和授权的应用程序管理员；商业可以显示缩短的买家钱包和交易链接 |

使用数据的保留期限在 [隐私政策](https://elata.bio/privacy)中列出。

<a id="your-choices"></a>

## 您的选择

- **相机和蓝牙：** 您的浏览器会在任何应用程序使用它们之前进行询问。您可以在浏览器的站点设置中撤销访问权限。
- **分数：** 随时打开或关闭共享。请参阅 [分数和见解](/cn/users/score-and-insights)。
- **提醒：** 应用程序只能通过 Elata 提醒您，在您允许之前提醒会关闭，并且每个应用程序都会记住您的选择。

<a id="experimental-recordings-on-this-device"></a>

## 该设备上的实验记录

 [本地会话集成](/cn/users/local-sessions-and-insights) 是仅限开发人员的实验，在生产中禁用。其原始生物信号记录使用浏览器存储，并且不会镜像到 Elata 的服务器。它们不会自动跟随您到另一台设备。清除浏览器存储可以将其删除。本地删除和服务器帐户删除是单独的操作。

<a id="access-export-and-deletion"></a>

## 访问、导出和删除

根据 Elata 的 [隐私政策](https://elata.bio/privacy) ，您可以要求访问、更正、删除、导出或限制您的个人数据。使用您帐户上的地址发送电子邮件至 [info@elata.bio](mailto:info@elata.bio) 。该政策承诺在 30 天内做出回应。

Elata 上的应用程序由独立开发人员构建。如果应用程序链接到其自己的隐私条款，则这些条款适用于该应用程序在 Elata 之外执行的任何操作。

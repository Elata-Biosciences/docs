## 登录

使用社交账号登录，如果已有钱包也可以连接钱包。登录后，你可以收藏应用、跨设备保存进度、发表评价，并赚取 [Elata 积分](/cn/overview/points)。

---

## 查找应用

首页会展示精选和推荐的应用，推荐会随着你的使用越来越个性化。按类别浏览：

| 类别 | 示例 |
| --- | --- |
| **Games（游戏）** | 根据你的心率或脑电信号做出反应的游戏 |
| **Neurometrics（神经测量）** | 实时 EEG 和心率面板 |
| **Wellness（健康）** | 呼吸练习、冥想和恢复 |
| **Tools（工具）** | 专注计时器和自我追踪 |
| **Experiments（实验）** | 研究、原型和科研应用 |

## 应用页面

每个应用都有一个页面，包括：

- **概览**：描述、截图和链接
- **评价**和**社区**评论
- **团队**：开发者是谁
- **更新**：版本说明

---

## 使用应用

1. 打开应用页面。
2. 点击 **Play**。
3. 如果应用请求，授予摄像头或蓝牙权限。

应用直接在浏览器中运行。不同应用的需求：

| 应用类型 | 你需要 |
| --- | --- |
| 摄像头（rPPG） | 网络摄像头和现代浏览器 |
| EEG 头带 | 受支持的头带（如 Muse）以及支持 Web Bluetooth 的 Chromium 内核浏览器 |

部分应用提供应用内物品或月度订阅。购买始终通过 Elata 的结账流程进行，绝不通过应用本身。

<Tip>
  你可以在应用的试玩页面将其添加到主屏幕，之后可直接打开该应用。
</Tip>

## 你的数据

生物信号在你的设备上处理。只有在你明确允许后，应用才能将派生的会话结果贡献给你的跨应用评分，你也可以随时更改。参见[隐私与数据](/cn/overview/privacy-and-consent)。

## 你的活动

- **Saved**：你收藏的应用
- **Insights**：你在各应用中的活动和评分
- **Points**：你的 Elata 积分余额和历史
- **Notifications**：你关注的应用和用户的动态

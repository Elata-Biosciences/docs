<a id="what-each-kind-of-app-needs"></a>

## 各类应用需要什么

| 应用类型 | 您需要 | 浏览器 |
| --- | --- | --- |
| **摄像头 (rPPG)** | 任何内置或 USB 网络摄像头 | 现代浏览器，包括 Safari |
| **EEG 头带** | Muse 2、 Muse S，或 Muse S (Athena) | Chrome 或 Edge 在桌面或 Android 上 |
| **头带心率 (PPG)** | A Muse 带有光学传感器的头带，例如 Muse S | Chrome 或 Edge 在桌面或 Android 上 |

 Elata 上的每个应用程序页面都说明了它的需求。

<a id="browser-support"></a>

## 浏览器支持

| | Chrome / Edge | Safari (Mac) | iPhone 和 iPad |
| --- | --- | --- | --- |
| 相机应用程序 | 是 | 是 | 是，需要相机权限 |
| 蓝牙头带 | 是，在 `https` 页面 | 否 | 否 |

蓝牙头带使用 **Web Bluetooth**，其中 Safari 和所有 iOS 浏览器
不支持。在这些设备上，使用相机应用程序。

<a id="tips-for-camera-apps"></a>

## 相机应用程序提示

- **均匀照亮您的脸部**，最好面向窗户或灯。避免来自身后的强光。
- **避免闪烁。** 一些 LED 灯和荧光灯闪烁会干扰阅读。
- **静静地坐着** 并将您的脸部保持在画面中，距离相机大约一臂长度。
- **稍等一下。** 稳定视频几秒后读数稳定。

<a id="tips-for-headbands"></a>

## 头带小贴士

- **紧密贴合。** 传感器应接触前额和耳后的皮肤。
- **将头发从耳后的传感器移到一边** 。
- **放松脸部和下巴。** 用力眨眼、咬紧牙关和说话会产生大信号，但这些信号并非大脑活动。
- **打开蓝牙** 并使头带保持充电并在附近。
- **从应用程序配对，** 不从计算机的蓝牙设置进行配对。

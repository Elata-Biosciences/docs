<a id="what-each-kind-of-app-needs"></a>

## 每种类型的应用程序需要什么

| 应用程序类型 | 你需要 | 浏览器 |
| --- | --- | --- |
| **相机（rPPG）** | 任何网络摄像头，内置或 USB | 现代浏览器，包括 Safari |
| **EEG 头带** | Muse 2、Muse S 或 Muse S (雅典娜) | 桌面版或 Android 版 Chrome 或 Edge |
| **头带心率 (PPG)** | 带有光学传感器的 Muse 头带，例如 Muse S | 桌面版或 Android 版 Chrome 或 Edge |

Elata 上的每个应用程序页面都说明了它的需求。

<a id="browser-support"></a>

## 浏览器支持

|| 镀铬/边缘 | Safari（苹果机） | iPhone 和 iPad |
| --- | --- | --- | --- |
| 相机应用程序 | 是 | 是 | 是的，需要相机许可 |
| 蓝牙头带 | 是的，在 `https` 页上 | 否 | 否 |

蓝牙头带使用 **Web 蓝牙**，Safari 和所有 iOS 浏览器不支持。在这些设备上，使用相机应用程序。

<a id="tips-for-camera-apps"></a>

## 相机应用程序的提示

- **均匀照亮您的脸**，最好面向窗户或灯。避免来自身后的强光。
- **避免闪烁。** 一些 LED 灯和荧光灯闪烁会干扰阅读。
- **静静地坐着** 并将您的脸部保持在画面中，距离相机大约一臂长度。
- **请稍等一下。** 稳定视频几秒后读数稳定。

<a id="tips-for-headbands"></a>

## 头带小贴士

- **紧密贴合。** 传感器应接触前额和耳后的皮肤。
- **将头发从耳后的传感器移到一边** 。
- **放松脸部和下巴。** 用力眨眼、咬紧牙关和说话会产生大信号，但这些信号并非大脑活动。
- **打开蓝牙** 并使头带保持充电并在附近。
- **从应用程序配对，** 不从计算机的蓝牙设置配对。

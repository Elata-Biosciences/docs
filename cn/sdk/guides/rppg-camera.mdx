## 本指南涵盖的内容

本指南展示如何：

- 在浏览器中采集网络摄像头画面
- 检测人脸并提取面部区域
- 将样本输入 rPPG 处理器
- 读取实时 BPM 和信号质量
- 在有 Muse PPG 时改进估算结果

## 开始之前

你需要：

- `@elata-biosciences/rppg-web`
- 支持摄像头访问（`getUserMedia`）和 WebAssembly 的浏览器
- `https://` 或 `localhost`

<CodeGroup>

```bash npm
npm install @elata-biosciences/rppg-web
```

```bash pnpm
pnpm add @elata-biosciences/rppg-web
```

</CodeGroup>

<Info>
当面部光线充足、基本保持静止并完整出现在画面中时，rPPG 效果最好。
</Info>

<Tip>
大多数应用应使用 `createRppgSession()`，它封装了本页的所有内容（WASM 初始化、帧采集、ROI 选择、诊断、清理）。参见[在浏览器应用中使用 rPPG](/cn/sdk/guides/rppg-browser)。只有在需要自定义编排时，才使用下面的底层组件。
</Tip>

## 使用 DemoRunner 快速集成

`DemoRunner` 在一个流程中处理帧采集、人脸检测、ROI 提取和处理，同时让你保留对处理器的控制。

```ts
import {
  RppgProcessor,
  MediaPipeFrameSource,
  DemoRunner,
  loadWasmBackend,
} from "@elata-biosciences/rppg-web";

const video = document.querySelector("video")!; // 正在播放的摄像头 <video>
const backend = await loadWasmBackend(); // 无法加载打包的 WASM 时返回 null
if (!backend) throw new Error("rPPG WASM backend unavailable");
const source = new MediaPipeFrameSource(video);
const processor = new RppgProcessor(backend, 30);

const runner = new DemoRunner(source, processor, {
  useSkinMask: true,
  onStats: () => {
    const metrics = processor.getMetrics();

    document.getElementById("bpm")!.textContent =
      metrics.bpm?.toFixed(0) ?? "--";

    document.getElementById("quality")!.textContent =
      `${(metrics.confidence * 100).toFixed(0)}%`;
  },
});

await runner.start();
```

<Tip>
只在 `metrics.confidence` 高于应用阈值时显示 BPM。0.5 左右是比较实用的起点。
</Tip>

## 手动流水线

当你需要更精细地控制人脸追踪、采样或中间结果的渲染方式时，使用手动路径。

<Steps>
  <Step title="加载人脸模型并创建帧来源">

  ```ts
  import {
    MediaPipeFaceFrameSource,
    loadFaceLandmarker,
  } from "@elata-biosciences/rppg-web";

  // 从 CDN 加载 MediaPipe FaceLandmarker；不可用时返回 null。
  const faceLandmarker = await loadFaceLandmarker();
  if (!faceLandmarker) throw new Error("Face tracking unavailable");
  const source = new MediaPipeFaceFrameSource(video, faceLandmarker);
  ```

  </Step>

  <Step title="创建处理器">

  ```ts
  import { RppgProcessor, loadWasmBackend } from "@elata-biosciences/rppg-web";

  const backend = await loadWasmBackend();
  if (!backend) throw new Error("rPPG WASM backend unavailable");
  const processor = new RppgProcessor(backend, 30, 10);
  ```

  第三个参数将分析窗口设置为 10 秒。

  </Step>

  <Step title="从面部 ROI 输入样本">

  ```ts
  import { averageGreenInROI } from "@elata-biosciences/rppg-web";

  source.onFrame = (frame) => {
    if (!frame.roi) return;

    const { x, y, w, h } = frame.roi;
    const green = averageGreenInROI(frame, x, y, w, h);

    processor.pushSample(
      frame.timestampMs ?? performance.now(),
      green,
    );
  };
  ```

  </Step>

  <Step title="启动摄像头并读取指标">

  ```ts
  await source.start();

  setInterval(() => {
    const metrics = processor.getMetrics();
    console.log("BPM:", metrics.bpm, "confidence:", metrics.confidence);
  }, 1000);
  ```

  </Step>
</Steps>

## 添加 Muse 校准

如果有 Muse 设备，你可以将其 PPG 作为参考信号来改进基于摄像头的估算。

```ts
// `processor` 是上面创建的 RppgProcessor
processor.updateMuseMetrics(museBpm, 0.9, performance.now());
```

<Info>
更完整的融合流程（包括 `MuseFusionCalibrator` 和校准模型）请继续阅读[校准](/cn/sdk/rppg-web/calibration)。
</Info>

## 质量检查清单

在调试流水线之前，请先检查：

- 保持面部光线均匀
- 减少头部移动
- 在信任早期 BPM 输出前等待 5 到 10 秒
- 确认确实检测到了面部 ROI
- 使用 `DemoRunner` 时启用 `useSkinMask`

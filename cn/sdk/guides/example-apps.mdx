## 这些应用展示了什么

每个应用都是使用已发布的 `@elata-biosciences` 包的独立仓库：

| 包 | 用途 |
| --- | --- |
| `@elata-biosciences/eeg-web` | EEG 信号处理和模型 |
| `@elata-biosciences/eeg-web-ble` | Web Bluetooth 头带数据流 |
| `@elata-biosciences/rppg-web` | 基于摄像头的心率测量 |

当你需要了解真实产品如何组织 SDK 会话、状态管理、图表和清理时，这些应用可以作为参考实现。

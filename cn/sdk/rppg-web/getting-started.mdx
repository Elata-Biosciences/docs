## 什么是 rPPG？

远程光电容积脉搏波描记（rPPG）通过普通摄像头捕捉面部皮肤细微的颜色变化来提取心率。无需接触式传感器，只需一个网络摄像头。

---

## 何时使用此包

当你的应用需要以下功能时，使用 `@elata-biosciences/rppg-web`：

- 在浏览器中进行基于摄像头的生物信号处理
- 更高层的 rPPG 会话 API，而不是直接编排 WASM
- 围绕 rPPG 会话的诊断和面向应用的辅助函数

---

## 安装

<CodeGroup>

```bash pnpm
pnpm add @elata-biosciences/rppg-web
```

```bash npm
npm install @elata-biosciences/rppg-web
```

</CodeGroup>

要求：Node.js 20+，支持摄像头访问和 WebAssembly 的浏览器。

## 推荐用法：`createRppgSession`

对于大多数浏览器应用，请从 `createRppgSession()` 开始。它负责 WASM 初始化、帧采集、ROI 编排、诊断和清理。

```typescript
import { createRppgSession } from "@elata-biosciences/rppg-web";

const session = await createRppgSession({
  video: videoEl,
  sampleRate: 30,
  backend: "auto",
  faceMesh: "off",
  onDiagnostics: (diagnostics) => {
    console.log(diagnostics.state.status, diagnostics.faceTrackingMode);
    console.log(diagnostics.framesSeen, diagnostics.totalSamplesReceived);
  },
});

const metrics = session.getMetrics();
console.log("BPM:", metrics.bpm);

// 清理时停止并释放摄像头
await session.stop();
```

如果还希望在处理器发生终止性故障后自动重启，请使用 `createManagedRppgSession()`。

---

## 诊断建议

每个会话的诊断数据都包含状态、问题代码、采样统计和处理器故障信息。

- 如果 `session.state.status` 变为 `failed`，请将底层处理器视为已终止并重新创建会话。
- 如果 `backend: "auto"` 回退到不可用的后端模式，诊断信息会报告该状态，而不是静默失败。

## 高级：`RppgProcessor`

如需自定义编排，可以直接使用 `RppgProcessor`。只有在需要 `createRppgSession()` 无法提供的功能时才这样做。调试时，请先与 `createRppgSession()` 进行对比。

```typescript
import { RppgProcessor, loadWasmBackend } from "@elata-biosciences/rppg-web";

const backend = await loadWasmBackend(); // 无法加载打包的 WASM 时返回 null
if (!backend) throw new Error("rPPG WASM backend unavailable");
const processor = new RppgProcessor(backend, 30); // backend, sampleRate

// 每帧输入来自面部 ROI 的绿色通道强度
processor.pushSample(performance.now(), greenIntensity);

const metrics = processor.getMetrics();
console.log("BPM:", metrics.bpm);
```

### 构造函数

```typescript
new RppgProcessor(backend: Backend, sampleRate: number, windowSeconds?: number)
```

| 参数 | 类型 | 说明 |
|-----------|------|-------------|
| `backend` | `Backend` | 后端对象，通常来自 `loadWasmBackend()` |
| `sampleRate` | `number` | 预期的每秒帧数（例如 30） |
| `windowSeconds` | `number` | 分析窗口长度（秒），默认 5 |

### 输入样本

```typescript
processor.pushSample(timestampMs, intensity);           // 仅绿色通道
processor.pushSampleRgb(timestampMs, r, g, b, skinRatio?);
processor.pushSampleRgbMeta(timestampMs, r, g, b, skinRatio?, motion?, clipRatio?);
```

### 指标

| 字段 | 类型 | 说明 |
|-------|------|-------------|
| `bpm` | `number \| null` | 最终心率估算。预热期间（约 10 秒）或后端不可用时为 `null`。 |
| `confidence` | `number` | 0 到 1。请据此控制界面：仅在高于阈值（例如 0.5）时显示 BPM。 |
| `signal_quality` | `number` | 0 到 1 的原始摄像头信号质量，基于皮肤占比、运动和过曝 |
| `spectral_bpm` | `number \| null` | 频域（FFT）估算 |
| `acf_bpm` | `number \| null` | 自相关估算 |
| `reason_codes` | `string[]` | 置信度低的原因，例如 `low_skin_ratio` 或 `high_motion` |

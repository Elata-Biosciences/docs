## 何时使用此包

当你的应用需要以下功能时，使用 `@elata-biosciences/eeg-web-ble`：

- 在浏览器端发现 Muse 兼容设备
- 通过 Web Bluetooth 实时输出 EEG 数据
- 用于应用逻辑或下游分析的规范化头带帧

请与 `@elata-biosciences/eeg-web` 一起安装。

---

## 安装

```bash
npm install @elata-biosciences/eeg-web-ble @elata-biosciences/eeg-web
```

`eeg-web-ble` 依赖 `eeg-web` 提供的共享帧类型和 WASM 模块。

---

## 要求

- 支持 **Web Bluetooth** 的浏览器（桌面或 Android 上的 Chrome/Edge）
- 通过**安全上下文**提供服务（`https://` 或 `localhost`）
- Safari/iOS **不**支持 Web Bluetooth。替代方案参见 [Muse 设备](/cn/sdk/eeg-web-ble/muse-device)

在显示“连接”按钮之前先检查支持情况：

```typescript
import { checkWebBluetooth } from "@elata-biosciences/eeg-web-ble";

const support = checkWebBluetooth();
if (!support.supported) {
  showMessage(support.message); // 说明原因，包括针对 iOS 的提示
}
```

## 基本用法

`startStreaming()` 是推荐的默认方式。它把 `connect()` 和 `start()` 合并在一起，避免了连接成功却从未开始数据流的常见错误。

```typescript
import { initEegWasm, AthenaWasmDecoder } from "@elata-biosciences/eeg-web";
import { BleTransport } from "@elata-biosciences/eeg-web-ble";

// 先初始化 WASM
await initEegWasm();

// 创建传输
const transport = new BleTransport({
  deviceOptions: {
    athenaDecoderFactory: () => new AthenaWasmDecoder(),
  },
});

// 处理传入的 EEG 帧
transport.onFrame = (frame) => {
  console.log(`EEG samples: ${frame.eeg.samples.length} rows`);
  console.log(`Channels: ${frame.eeg.channelNames.join(", ")}`);
};

// 处理连接状态变化
transport.onStatus = (status) => {
  console.log(`Transport: ${status.state}`, status.reason || "");
};

// 连接并开始数据流（会弹出蓝牙设备选择器）
await transport.startStreaming();

// ……之后
await transport.stop();
```

---

## BleTransport 生命周期

| 方法 | 作用 |
| --- | --- |
| `startStreaming()` | 推荐：一次调用完成连接并开始数据流 |
| `connect()` | 打开蓝牙设备选择器、配对并准备会话 |
| `start()` | 开始 EEG 数据流；`onFrame` 回调开始触发 |
| `stop()` | 停止数据流；连接保持打开 |
| `disconnect()` | 释放蓝牙会话 |

---

## BleTransportOptions

```typescript
const transport = new BleTransport({
  sourceName: "my-app-ble",           // frame.source 中的名称标签
  deviceOptions: {
    athenaDecoderFactory: () => new AthenaWasmDecoder(),  // 用于 Athena 头带
    logger: (msg) => console.debug(msg),
    onDisconnected: () => console.warn("Device disconnected"),
  },
});
```

| 选项 | 类型 | 说明 |
| --- | --- | --- |
| `sourceName` | `string` | 包含在 `HeadbandFrameV1.source` 中的标识 |
| `deviceOptions` | `MuseDeviceOptions` | 传给底层的 `MuseBleDevice` |
| `device` | `BleDeviceLike` | 注入自定义设备实现 |

## Athena 支持

采用 Athena 固件的 Muse S 头带需要 Athena 解码器工厂。预先加入它，可以同时覆盖经典版和 Athena 流程：

```typescript
import { AthenaWasmDecoder } from "@elata-biosciences/eeg-web";
import { BleTransport } from "@elata-biosciences/eeg-web-ble";

const transport = new BleTransport({
  deviceOptions: {
    athenaDecoderFactory: () => new AthenaWasmDecoder(),
  },
});
```

Athena 头带的每一帧都提供 8 路 EEG 通道、光学、加速度计/陀螺仪和电量数据。

---

## 设备信息

连接后，你可以查询设备元数据：

```typescript
await transport.connect();

const isAthena = transport.getIsAthena();
const boardInfo = transport.getBoardInfo();
const channelNames = transport.getEegNames();
```

---

## 平台注意事项

- Safari 和 iOS 不提供可用于此流程的 Web Bluetooth 支持。
- 对于 Safari 和 iOS，请使用原生 BLE 外壳、配套桥接或混合 WebView 方案，并以 `@elata-biosciences/eeg-web` 的帧协议作为边界。
- 不同固件版本的命令行为可能不同。

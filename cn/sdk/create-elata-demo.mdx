<a id="what-it-is"></a>

## 它是什么

`@elata-biosciences/create-elata-demo` 生成一个连接到 Elata SDK 的工作 Vite + React 应用程序。这是运行应用程序的最快方式，也是将 SDK 集成到您自己的项目之前的已知良好基准。

---

<a id="templates"></a>

## 模板

| 模板 | 别名 | 你得到什么 | 硬件 |
| --- | --- | --- | --- |
| `rppg-demo` | `rppg` | 相机脉冲和 rPPG 启动器。 **默认值。** | 网络摄像头 |
| `eeg-demo` | `eeg` | 用于 SDK 接线的浏览器 EEG 启动器，支持 Muse Web 蓝牙 | 缪斯（可选） |
| `eeg-ble` | `ble` | 蓝牙优先 EEG 启动器以及浏览器配对流程 | 缪斯 |
| `ppg-demo` | `ppg`, `muse-ppg` | 头带 PPG 启动器显示 BPM、RMSSD 和实时诊断 | 缪斯 |
| `pulse-game` | `pulse`, `recovery` | rPPG 恢复游戏，在沙盒 iframe 中运行并使用 `app-metrics`保存分数，端到端 | 网络摄像头 |

<Tip>
为Elata建造？ `pulse-game` 显示了完整的 Elata 模式：应用程序在 iframe 中运行，并通过 [指标桥](/cn/apps/platform/metrics-and-scores)与主机对话。
</Tip>

<a id="usage"></a>

## 用途

<CodeGroup>

```bash npm
# Interactive: pick a template, then a project name
npm create @elata-biosciences/elata-demo my-app

# Pick a template directly
npm create @elata-biosciences/elata-demo my-app -- --template rppg
npm create @elata-biosciences/elata-demo my-app -- --template eeg-ble
npm create @elata-biosciences/elata-demo my-app -- --template ppg
npm create @elata-biosciences/elata-demo my-app -- --template pulse-game

# List templates
npx @elata-biosciences/create-elata-demo --list-templates
```

```bash pnpm
pnpm create @elata-biosciences/elata-demo my-app
pnpm create @elata-biosciences/elata-demo my-app -- --template rppg
pnpm dlx @elata-biosciences/create-elata-demo --list-templates
```

</CodeGroup>

| 旗帜 | 含义 |
| --- | --- |
| `--template <name>` 或 `--template=<name>` | 选择模板或别名 |
| `--list-templates` | 打印可用的模板 |

如果没有 `--template`，CLI 会要求您在交互运行时选择一个，否则使用 `rppg-demo` 。如果您省略项目目录，它会要求输入名称。

<a id="what-you-get"></a>

## 你得到什么

每个生成的应用程序都包括：

- 一个 Vite + React + TypeScript 应用程序
- Elata 软件包固定到一组兼容的版本
- 特定于模板的 `README.md`
- `npm run dev`：启动开发服务器
- `npm run build`：类型检查并构建为 `dist/`
- `npm run build:zip`：构建并编写 `app.zip`，准备 [上传到Elata](/cn/apps/build/launch-your-app)

```bash
cd my-app
npm install
npm run dev
```

<a id="inside-another-pnpm-workspace"></a>

## 在另一个 pnpm 工作区中

如果您在不包含新文件夹的现有 `pnpm` 工作区中搭建脚手架，请在工作区外安装并运行它：

```bash
pnpm --dir my-app --ignore-workspace install
pnpm --dir my-app --ignore-workspace run dev
```

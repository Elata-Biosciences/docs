## 何时使用此包

当你的应用需要以下功能时，使用 `@elata-biosciences/eeg-web`：

- 浏览器中的 EEG 分析 API
- 更高层集成使用的共享 EEG Web 协议
- 在浏览器端访问 Elata WASM 模型和信号处理函数

此包不实现蓝牙设备连接。如果还需要 Muse 兼容设备的实时浏览器传输，请添加 `@elata-biosciences/eeg-web-ble`。

<Tip>
  刚接触 SDK？在手动接入包之前，先使用 `create-elata-demo` 创建演示应用。参见[第一个应用教程](/cn/sdk/tutorials/first-app)。
</Tip>

## 安装

<CodeGroup>

```bash pnpm
pnpm add @elata-biosciences/eeg-web
```

```bash npm
npm install @elata-biosciences/eeg-web
```

</CodeGroup>

要求：服务器端使用和本地仓库工具需要 Node.js 20+；浏览器内使用需要支持 WebAssembly 的现代浏览器。

## WASM 初始化

在使用任何信号处理或模型 API 之前，先初始化 WASM 模块：

```typescript
import { initEegWasm } from "@elata-biosciences/eeg-web";

await initEegWasm();
```

`initEegWasm` 是幂等的，多次调用会返回同一个 Promise。如需同步初始化（例如在 Web Worker 中）：

```typescript
import { initEegWasmSync } from "@elata-biosciences/eeg-web";

initEegWasmSync(wasmModule);
```

## 基本用法

从 EEG 数据计算频段功率：

```typescript
import { initEegWasm, band_powers } from "@elata-biosciences/eeg-web";

await initEegWasm();

const sampleRate = 256;
const eegSamples = new Float32Array(/* ……单通道 EEG 样本…… */);

const powers = band_powers(eegSamples, sampleRate);
console.log("Alpha:", powers.alpha);
console.log("Beta:", powers.beta);
console.log("Theta:", powers.theta);
console.log("Delta:", powers.delta);
console.log("Gamma:", powers.gamma);
```

## 包结构

`@elata-biosciences/eeg-web` 是围绕 `wasm-bindgen` 生成的 WASM 绑定的一层轻量 TypeScript 封装：

- `initEegWasm` / `initEegWasmSync`：WASM 初始化辅助函数
- 头带帧类型：EEG 传输使用的规范化数据结构
- 所有 WASM API：从生成的绑定中重新导出

### 主要导出

- `initEegWasm`
- `initEegWasmSync`
- `band_powers`
- `WasmAlphaBumpDetector`
- `WasmAlphaPeakModel`
- `WasmCalmnessModel`
- `AthenaWasmDecoder`
- `createRppgPipeline`
- 帧辅助函数：`getEegChannelSamples`、`getEegInterleavedSamples`、`getEegSignalBlock`
- 预处理：`createEegPreprocessor`、`processHeadbandFrame`
- 错误：`ElataError`、`isElataError`、`asElataError`

<Note>
  生成的 `wasm-bindgen` 导出是为了兼容性和 SDK 调试而重新导出的。除非你确实在调试 SDK 本身，否则不要直接实例化生成的封装类。
</Note>

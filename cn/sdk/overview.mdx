## Elata SDK

 Elata SDK 是一组 npm 包，用于捕获和处理生物信号
浏览器。这些包构建在编译为 WebAssembly的 Rust 包上，因此发出信号
处理在用户的设备上运行。

<Info>
  **存储库**： [github.com/Elata-Biosciences/elata-bio-sdk](https://github.com/Elata-Biosciences/elata-bio-sdk) · **npm**: [`@elata-biosciences`](https://www.npmjs.com/org/elata-biosciences)
</Info>

---

<a id="quick-start"></a>

## 快速启动

最快的方法是构建一个入门应用程序：

```bash
# Interactive template picker
npm create @elata-biosciences/elata-demo my-app

# Or pick one directly
npm create @elata-biosciences/elata-demo my-app -- --template rppg
```

```bash
cd my-app
npm install
npm run dev
```

请参阅 [create-elata-demo](/cn/sdk/create-elata-demo) 了解所有五个模板。

<a id="add-packages-to-an-existing-app"></a>

## 将软件包添加到现有应用程序

```bash
# Camera heart rate
npm install @elata-biosciences/rppg-web

# EEG over Web Bluetooth
npm install @elata-biosciences/eeg-web @elata-biosciences/eeg-web-ble

# Headband PPG heart rate and HRV
npm install @elata-biosciences/ppg-web @elata-biosciences/eeg-web @elata-biosciences/eeg-web-ble @elata-biosciences/rppg-web
```

**要求**： Node.js 20 或更高版本的工具，以及支持 WebAssembly 的现代浏览器。

<a id="device-support"></a>

## 设备支持

| 设备 | 协议 | 信号 | 状态 |
| --- | --- | --- | --- |
| Muse 2 | 经典 BLE | 4 EEG （TP9、AF7、AF8、TP10）、 PPG | 支持 |
| Muse S | 经典 BLE | 4 EEG, PPG | 支持 |
| Muse S (Athena) | Athena | 8 EEG, 光学器件，加速度计/陀螺仪 | 支持 |
| 任何网络摄像头 | 摄像头 | rPPG 脉冲 | 支持 |

想要添加耳机吗？请参阅 [设备集成](/cn/integrate)。

<a id="rust-crates"></a>

## Rust 板条箱

这些软件包构建在公共 Rust 板条箱上，您也可以直接使用：

| 箱子 | 用途 |
| --- | --- |
| `elata-eeg-hal` | 核心设备特征： `EegDevice`、 `SampleBuffer` |
| `elata-eeg-signal` | FFT、频带功率、滤波 |
| `elata-eeg-models` | Alpha 碰撞探测器，平静模型 |
| `elata-rppg` | rPPG 管道核心 |
| `elata-muse-proto` | Muse 经典和 Athena 协议解码 |

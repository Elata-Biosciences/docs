## Elata 生物特征 SDK

Elata SDK 是一组在浏览器中采集和处理生物信号的 npm 包。它们基于编译为 WebAssembly 的 Rust crate 构建，因此信号处理在用户设备上运行。

<Info>
  **代码仓库**：[github.com/Elata-Biosciences/elata-bio-sdk](https://github.com/Elata-Biosciences/elata-bio-sdk) · **npm**：[`@elata-biosciences`](https://www.npmjs.com/org/elata-biosciences)
</Info>

---

## 快速开始

最快的方式是创建一个入门应用：

```bash
# 交互式选择模板
npm create @elata-biosciences/elata-demo my-app

# 或直接指定模板
npm create @elata-biosciences/elata-demo my-app -- --template rppg
```

```bash
cd my-app
npm install
npm run dev
```

全部五个模板见 [create-elata-demo](/cn/sdk/create-elata-demo)。

## 包

### 传感器

| 包 | 功能 |
| --- | --- |
| [`@elata-biosciences/rppg-web`](/cn/sdk/rppg-web/getting-started) | 通过网络摄像头获取心率和脉搏信号（rPPG）。默认起点：无需任何硬件。 |
| [`@elata-biosciences/eeg-web`](/cn/sdk/eeg-web/getting-started) | EEG 信号处理、频段功率和模型（WASM），以及共享的头带帧协议。 |
| [`@elata-biosciences/eeg-web-ble`](/cn/sdk/eeg-web-ble/getting-started) | 通过 Web Bluetooth 连接 EEG 头带。内置 Muse 支持，可扩展到其他设备。 |
| [`@elata-biosciences/ppg-web`](/cn/sdk/ppg-web/getting-started) | 通过头带的光学（PPG）传感器获取心率和 HRV。 |

### 录制与分析

| 包 | 功能 |
| --- | --- |
| [`@elata-biosciences/biosignal-session`](/cn/sdk/biosignal-session/getting-started) | 使用容错协议和 Arrow 分块将多传感器会话录制到本地存储。 |
| [`@elata-biosciences/biosignal-analytics`](/cn/sdk/biosignal-analytics/getting-started) | EEG 窗口特征、HRV、稳健统计和透明的总体评分。 |
| `@elata-biosciences/rppg-models-web` | 实验性：为 `rppg-web` 提供可选的学习型波形重建。需自行提供模型文件。 |

### 应用商店

| 包 | 功能 |
| --- | --- |
| [`@elata-biosciences/app-payments`](/cn/apps/platform/in-app-purchases) | 通过商店结账实现应用内购买 |
| [`@elata-biosciences/app-state`](/cn/apps/platform/app-state) | 按用户的键值存储 |
| [`@elata-biosciences/app-metrics`](/cn/apps/platform/metrics-and-scores) | 事件记录、分数以及生物特征评分贡献 |

### 工具

| 包 | 功能 |
| --- | --- |
| [`@elata-biosciences/create-elata-demo`](/cn/sdk/create-elata-demo) | 从模板创建入门应用 |

## 在现有应用中添加包

```bash
# 摄像头心率
npm install @elata-biosciences/rppg-web

# 基于 Web Bluetooth 的 EEG
npm install @elata-biosciences/eeg-web @elata-biosciences/eeg-web-ble

# 头带 PPG 心率和 HRV
npm install @elata-biosciences/ppg-web @elata-biosciences/eeg-web @elata-biosciences/eeg-web-ble @elata-biosciences/rppg-web
```

**要求**：工具链需要 Node.js 20 或更高版本，以及支持 WebAssembly 的现代浏览器。

## 设备支持

| 设备 | 协议 | 信号 | 状态 |
| --- | --- | --- | --- |
| Muse 2 | Classic BLE | 4 路 EEG（TP9、AF7、AF8、TP10）、PPG | 支持 |
| Muse S | Classic BLE | 4 路 EEG、PPG | 支持 |
| Muse S（Athena） | Athena | 8 路 EEG、光学、加速度计/陀螺仪 | 支持 |
| 任意网络摄像头 | 摄像头 | rPPG 脉搏 | 支持 |

想接入新的头戴设备？参见[设备集成](/cn/integrate)。

## Rust crate

这些包基于公开的 Rust crate 构建，你也可以直接使用：

| Crate | 用途 |
| --- | --- |
| `elata-eeg-hal` | 核心设备 trait：`EegDevice`、`SampleBuffer` |
| `elata-eeg-signal` | FFT、频段功率、滤波 |
| `elata-eeg-models` | Alpha 波峰检测器、平静度模型 |
| `elata-rppg` | rPPG 流水线核心 |
| `elata-muse-proto` | Muse classic 和 Athena 协议解码 |

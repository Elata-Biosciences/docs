## 概述

Elata 是一个用于构建和分发人体信号应用的平台：通过网络摄像头获取心率、通过消费级 EEG 头带获取脑电活动，等等。

它由三部分组成：

1. **生物特征 SDK**：在浏览器中跨设备采集和处理生物信号的 npm 包。
2. **设备端处理**：原始信号始终保留在用户的设备上。
3. **Elata 应用商店**：开发者在这里发布应用，用户在这里发现和使用应用，并内置登录、支付和存储功能。

## 为什么需要 Elata

消费级设备已经悄然成为生物信号传感器。手机或笔记本电脑的摄像头可以估算心率和呼吸；消费级 EEG 头带能够采集十年前还需要临床设备才能获取的脑电活动。

传感器已经在人们的口袋里。缺少的是建立在它们之上的标准应用层。如今，处理生物信号的公司通常会把用户数据发送到自己的服务器，而每个开发者都在从零重建相同的信号处理流程。

Elata 通过以下方式解决这个问题：

1. **公开发布的 SDK**，在不同设备间统一生物信号采集。
2. **设备端处理**，原始数据无需离开用户的设备。
3. **内置基础设施的应用商店**，开发者无需自建认证、支付、托管或存储，就能发布生物信号应用。

## Elata 提供什么

### 生物特征 SDK

| 包 | 功能 |
| --- | --- |
| `@elata-biosciences/rppg-web` | 通过普通网络摄像头获取心率和脉搏信号（rPPG），无需可穿戴设备。 |
| `@elata-biosciences/eeg-web` | 在浏览器中进行 EEG 信号处理和模型计算（WebAssembly）。 |
| `@elata-biosciences/eeg-web-ble` | 通过 Web Bluetooth 连接消费级 EEG 头带，内置 Muse 支持。 |
| `@elata-biosciences/ppg-web` | 通过头带的光学（PPG）传感器获取心率和 HRV。 |
| `@elata-biosciences/biosignal-session` | 在本地录制多传感器会话。 |
| `@elata-biosciences/biosignal-analytics` | 从录制的信号中计算特征、HRV 和总体评分。 |

完整列表见 [SDK 概览](/cn/sdk/overview)。

### 隐私优先

信号处理在浏览器中完成。原始摄像头画面和原始生物信号无需离开设备。用户可以选择分享**派生的**会话结果，用于构建跨应用评分，并且可以随时关闭。参见[隐私与数据](/cn/learn/privacy-and-data)。

### 应用商店

开发者上传 Web 构建产物。商店会对其进行扫描和审核，将其托管在安全的沙箱中，并通过一组[平台 API](/cn/apps/platform/host-bridge) 为它提供登录、应用内购买、订阅和按用户存储。

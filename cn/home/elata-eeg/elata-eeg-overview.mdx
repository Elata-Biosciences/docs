<a id="what-is-elata-eeg"></a>

## Elata EEG是什么？

Elata EEG 是一个开源脑电图平台，围绕 [Raspberry Pi 5](https://www.raspberrypi.com/products/raspberry-pi-5/) 和 [Texas Instruments ADS1299](https://www.ti.com/product/ADS1299) 模拟前端构建。目标是通过完全开放、有权修复的设计使 EEG 硬件民主化，任何实验室或黑客都可以构建、修改和扩展。

该系统支持研究级分辨率的 8 个以上 24 位 EEG 通道，具有实时流、基于插件的 DSP 管道和基于浏览器的信息亭 UI。

<a id="hardware"></a>

## 硬件

| 组件 | 详情 |
| -------------- | ------------------------------------------------------------ |
| **控制器** | Raspberry Pi 5（四核 Arm Cortex，40 针 GPIO） |
| **ADC** | TI ADS1299 EEGFE：通过 SPI 的 8 通道、24 位模拟前端 |
| **电极** | 湿Ag/AgCl或带有导电膏的金杯（例如Ten20） |
| **显示** | 5英寸或7英寸HDMI触摸屏（可选） |
| **电缆** | 杜邦跳线 (2.54 mm)，可选屏蔽/铁氧体磁珠 |

支持两种板配置：

- **V1**：单 ADS1299 EVM（8 通道）
- **V2**：四个具有共享时钟和 SPI 的同步 ADS1299 EVM（32 通道）

<a id="software-stack"></a>

## 软件堆栈

| 图层 | 技术 |
| ---------------------- | ---------------------------------------------------------------- |
| **操作系统** | 树莓派操作系统 (Debian) |
| **固件/后端** | Rust 工作区： `sensors`、 `boards`、 `pipeline`、 `daemon` 箱子 |
| **前端** | 具有 WebSocket 数据流的 Next.js 信息亭 |
| **硬件接口** | `rppal` 箱子（GPIO / SPI / I2C） |
| **插件系统** | 共享 `EventBus`上的事件驱动 DSP 插件 |
| **许可证** | GPLv3（强版权左） |

<a id="quickstart"></a>

## 快速入门

```bash
git clone https://github.com/Elata-Biosciences/elata-eeg
cd elata-eeg
bash scripts/install.sh
```

安装脚本处理系统依赖项（Rust、 Node.js、Chromium）、构建所有 crate 和 kiosk、为守护程序和 kiosk 配置 systemd 服务、设置自动登录和 kiosk 模式，并在完成后重新启动。

<a id="development-mode"></a>

### 发展模式

```bash
# Stop kiosk mode
bash scripts/stop.sh

# Terminal 1: daemon (from repo root)
cargo run --bin eeg_daemon -- --mock   # --mock for testing without hardware

# Terminal 2: kiosk
cd kiosk && npm run dev
```

信息亭用户界面可通过 `http://localhost:3000`获取。 WebSocket 数据端点在 `ws://localhost:9000/ws/data`运行。

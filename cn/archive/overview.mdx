## 已停用的功能

应用程序代币、质押和治理目前已从当前产品中退出，并打算稍后返回。未来的设计和时序尚未承诺。旧链接重定向到当前指南，而不是暗示这些功能现在可用。

| 已退役 | 今天 |
| --- | --- |
| 为每个应用程序启动代币、联合曲线和交易应用程序代币 | 应用程序注册需一次性付费；没有启动代币 |
| 应用程序、锦标赛和 veELTA 页面的质押 | 不属于实时产品的一部分 |
| “高级内容” | [应用内购买](/cn/apps/platform/in-app-purchases)与[订阅](/cn/apps/platform/subscriptions) |
| API 参考选项卡 | [主桥](/cn/apps/platform/host-bridge) |

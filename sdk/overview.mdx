## Elata Biometric SDKs

The Elata SDKs are npm packages for capturing and processing biosignals in the
browser. They're built on Rust crates compiled to WebAssembly, so signal
processing runs on the user's device.

<Info>
  **Repository**: [github.com/Elata-Biosciences/elata-bio-sdk](https://github.com/Elata-Biosciences/elata-bio-sdk) · **npm**: [`@elata-biosciences`](https://www.npmjs.com/org/elata-biosciences)
</Info>

---

## Quick start

The fastest path is to scaffold a starter app:

```bash
# Interactive template picker
npm create @elata-biosciences/elata-demo my-app

# Or pick one directly
npm create @elata-biosciences/elata-demo my-app -- --template rppg
```

```bash
cd my-app
npm install
npm run dev
```

See [create-elata-demo](/sdk/create-elata-demo) for all five templates.

## Packages

### Sensors

| Package | What it does |
| --- | --- |
| [`@elata-biosciences/rppg-web`](/sdk/rppg-web/getting-started) | Heart rate and pulse signals from a webcam (rPPG). The default starting point: no hardware needed. |
| [`@elata-biosciences/eeg-web`](/sdk/eeg-web/getting-started) | EEG signal processing, band powers, and models (WASM), plus the shared headband frame contract. |
| [`@elata-biosciences/eeg-web-ble`](/sdk/eeg-web-ble/getting-started) | Connect EEG headbands over Web Bluetooth. Muse built in; extensible to other devices. |
| [`@elata-biosciences/ppg-web`](/sdk/ppg-web/getting-started) | Heart rate and HRV from a headband's optical (PPG) sensor. |

### Recording and analysis

| Package | What it does |
| --- | --- |
| [`@elata-biosciences/biosignal-session`](/sdk/biosignal-session/getting-started) | Record multi-sensor sessions to local storage with a fault-tolerant protocol and Arrow chunks. *Not yet on npm.* |
| [`@elata-biosciences/biosignal-analytics`](/sdk/biosignal-analytics/getting-started) | EEG window features, HRV, robust statistics, and transparent headline scores. *Not yet on npm.* |
| `@elata-biosciences/rppg-models-web` | Experimental: optional learned waveform reconstruction for `rppg-web`. You supply the model file. *Not yet on npm.* |

### App Store

| Package | What it does |
| --- | --- |
| [`@elata-biosciences/app-payments`](/apps/platform/in-app-purchases) | In-app purchases through the store checkout |
| [`@elata-biosciences/app-state`](/apps/platform/app-state) | Per-user key-value storage. *Not yet on npm; use the [`elata:state:*` messages](/apps/platform/app-state).* |
| [`@elata-biosciences/app-metrics`](/apps/platform/metrics-and-scores) | Event records, scores, and biometric Score contribution |

### Tooling

| Package | What it does |

## Add packages to an existing app

```bash
# Camera heart rate
npm install @elata-biosciences/rppg-web

# EEG over Web Bluetooth
npm install @elata-biosciences/eeg-web @elata-biosciences/eeg-web-ble

# Headband PPG heart rate and HRV
npm install @elata-biosciences/ppg-web @elata-biosciences/eeg-web @elata-biosciences/eeg-web-ble @elata-biosciences/rppg-web
```

**Requirements**: Node.js 20 or newer for tooling, and a modern browser with WebAssembly support.

## Device support

| Device | Protocol | Signals | Status |
| --- | --- | --- | --- |
| Muse 2 | Classic BLE | 4 EEG (TP9, AF7, AF8, TP10), PPG | Supported |
| Muse S | Classic BLE | 4 EEG, PPG | Supported |
| Muse S (Athena) | Athena | 8 EEG, optics, accelerometer/gyro | Supported |
| Any webcam | Camera | rPPG pulse | Supported |

Want to add a headset? See [Device Integration](/integrate).

## Rust crates

The packages are built on public Rust crates you can also use directly:

| Crate | Purpose |
| --- | --- |
| `elata-eeg-hal` | Core device traits: `EegDevice`, `SampleBuffer` |
| `elata-eeg-signal` | FFT, band power, filtering |
| `elata-eeg-models` | Alpha bump detector, calmness model |
| `elata-rppg` | rPPG pipeline core |
| `elata-muse-proto` | Muse classic and Athena protocol decoding |

## What it is

`@elata-biosciences/create-elata-demo` generates a working Vite + React app
wired to the Elata SDK. It's the fastest way to a running app, and a
known-good baseline before you integrate the SDKs into your own project.

---

## Templates

| Template | Aliases | What you get | Hardware |
| --- | --- | --- | --- |
| `rppg-demo` | `rppg` | Camera pulse and rPPG starter. **The default.** | Webcam |
| `eeg-demo` | `eeg` | Browser EEG starter for SDK wiring, with Muse Web Bluetooth support | Muse (optional) |
| `eeg-ble` | `ble` | Bluetooth-first EEG starter with the browser pairing flow | Muse |
| `ppg-demo` | `ppg`, `muse-ppg` | Headband PPG starter showing BPM, RMSSD, and live diagnostics | Muse |
| `pulse-game` | `pulse`, `recovery` | rPPG recovery game that runs in a sandboxed iframe and saves scores with `app-metrics`, end to end | Webcam |

<Tip>
  Building for Elata? `pulse-game` shows the full Elata pattern:
  the app runs in an iframe and talks to a host over the
  [metrics bridge](/apps/platform/metrics-and-scores).
</Tip>

## Usage

<CodeGroup>

```bash npm
# Interactive: pick a template, then a project name
npm create @elata-biosciences/elata-demo my-app

# Pick a template directly
npm create @elata-biosciences/elata-demo my-app -- --template rppg
npm create @elata-biosciences/elata-demo my-app -- --template eeg-ble
npm create @elata-biosciences/elata-demo my-app -- --template ppg
npm create @elata-biosciences/elata-demo my-app -- --template pulse-game

# List templates
npx @elata-biosciences/create-elata-demo --list-templates
```

```bash pnpm
pnpm create @elata-biosciences/elata-demo my-app
pnpm create @elata-biosciences/elata-demo my-app -- --template rppg
pnpm dlx @elata-biosciences/create-elata-demo --list-templates
```

</CodeGroup>

| Flag | Meaning |
| --- | --- |
| `--template <name>` or `--template=<name>` | Choose a template or alias |
| `--list-templates` | Print the available templates |

Without `--template`, the CLI asks you to pick one when run interactively, and
uses `rppg-demo` otherwise. If you leave out the project directory, it asks for
a name.

## What you get

Every generated app includes:

- a Vite + React + TypeScript app
- Elata packages pinned to a compatible set of versions
- a template-specific `README.md`
- `npm run dev`: start the dev server
- `npm run build`: type-check and build to `dist/`
- `npm run build:zip`: build and write `app.zip`, ready to [upload to Elata](/apps/build/launch-your-app)

```bash
cd my-app
npm install
npm run dev
```

---

## Inside another pnpm workspace

If you scaffold inside an existing `pnpm` workspace that doesn't include the new
folder, install and run it outside the workspace:

```bash
pnpm --dir my-app --ignore-workspace install
pnpm --dir my-app --ignore-workspace run dev
```

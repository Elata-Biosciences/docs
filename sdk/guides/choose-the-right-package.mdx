## Start here

1. **New app or just evaluating?** Use [`create-elata-demo`](/sdk/create-elata-demo). You'll have a working app in minutes.
2. **Existing app?** Add the package for the capability you need, from the table below.
3. **Publishing to the App Store?** Add the [App Store packages](#app-store-packages) for purchases, storage, and scores.

---

## By goal

| I want to... | Use | Install with |
| --- | --- | --- |
| Measure heart rate from a webcam | [`rppg-web`](/sdk/rppg-web/getting-started) | |
| Process EEG in the browser (band powers, models) | [`eeg-web`](/sdk/eeg-web/getting-started) | |
| Connect an EEG headband over Bluetooth | [`eeg-web-ble`](/sdk/eeg-web-ble/getting-started) | `eeg-web` |
| Get heart rate and HRV from a headband's PPG sensor | [`ppg-web`](/sdk/ppg-web/getting-started) | `eeg-web`, `eeg-web-ble`, `rppg-web` |
| Record a session from one or more sensors | [`biosignal-session`](/sdk/biosignal-session/getting-started) | the sensor packages you record from |
| Compute features, HRV, and headline scores | [`biosignal-analytics`](/sdk/biosignal-analytics/getting-started) | |
| Experiment with learned rPPG waveform reconstruction | `rppg-models-web` (experimental) | `rppg-web` |

These only work when your app runs inside the [Elata App Store](/apps/build/overview):

| --- | --- |

## Common mistakes

<Warning>
  These cause most first-run problems.
</Warning>

- **Installing `eeg-web-ble` without `eeg-web`.** The Bluetooth transport depends on it.
- **Expecting Web Bluetooth in Safari or on iOS.** Use Chrome or Edge on desktop or Android. See [Compatibility](/sdk/operations/compatibility).
- **Serving over plain `http://`.** Camera and Bluetooth need `https://` or `localhost`.
- **Assuming a scaffolded app is broken inside another pnpm workspace.** Install it with `pnpm --dir my-app --ignore-workspace install`.

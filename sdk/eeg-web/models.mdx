All three models share the same shape:

- construct with `new Model(sampleRateHz, channelCount)`
- call `process(interleaved)` with a `Float32Array` of **interleaved** samples (`[s0_ch0, s0_ch1, …, s1_ch0, …]`); `getEegInterleavedSamples(frame)` produces this from a headband frame
- `process` returns a result object, or `undefined` until enough data has accumulated (`min_samples()` tells you how much)
- call `reset()` to clear state

Because `channelCount` is only known once the first frame arrives, construct models inside your first-frame handler.

## WasmAlphaBumpDetector

Detects alpha bumps: transient changes in alpha band power that indicate state transitions, such as eyes closing.

```typescript
import { initEegWasm, WasmAlphaBumpDetector, getEegInterleavedSamples } from "@elata-biosciences/eeg-web";

await initEegWasm();

const detector = new WasmAlphaBumpDetector(256, 4); // sampleRateHz, channelCount

const result = detector.process(getEegInterleavedSamples(frame));
if (result?.state_changed) {
  console.log(result.state, result.alpha_power, result.baseline); // state: "high" | "low" | "transitioning" | "unknown"
}
```

Tune with `set_threshold(multiplier)` and `set_baseline_smoothing(alpha)`.

## WasmAlphaPeakModel

Tracks the individual alpha peak frequency (typically 8 to 13 Hz), which varies from person to person.

```typescript
import { WasmAlphaPeakModel } from "@elata-biosciences/eeg-web";

const model = new WasmAlphaPeakModel(256, 4);

const result = model.process(interleaved);
if (result) {
  console.log(result.peak_frequency, result.smoothed_peak_frequency, result.snr);
}
```

---

## WasmCalmnessModel

Computes a calmness score from the ratio of alpha to beta power. Higher alpha relative to beta generally indicates a more relaxed state.

```typescript
import { WasmCalmnessModel } from "@elata-biosciences/eeg-web";

const model = new WasmCalmnessModel(256, 4);

const result = model.process(interleaved);
if (result) {
  console.log(result.score);          // 0.0 (alert) to 1.0 (very calm)
  console.log(result.smoothed_score); // less jittery
  console.log(result.alpha_beta_ratio);
}
```

## AthenaWasmDecoder

Decodes raw Athena protocol packets from Muse S (Athena firmware) headbands. Used as a factory parameter for `BleTransport`:

```typescript
import { AthenaWasmDecoder } from "@elata-biosciences/eeg-web";

const decoder = new AthenaWasmDecoder();

decoder.reset();
decoder.set_use_device_timestamps(true);
decoder.set_clock_kind("monotonic");
decoder.set_reorder_window_ms(50);

const output = decoder.decode(rawBytes);
```

The Athena decoder is typically not used directly. It is passed as a factory to [`BleTransport`](/sdk/eeg-web-ble/getting-started):

```typescript
import { BleTransport } from "@elata-biosciences/eeg-web-ble";
import { AthenaWasmDecoder } from "@elata-biosciences/eeg-web";

const transport = new BleTransport({
  deviceOptions: {
    athenaDecoderFactory: () => new AthenaWasmDecoder(),
  },
});
```

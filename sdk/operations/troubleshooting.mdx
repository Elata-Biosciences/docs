## `pnpm install` Did Not Create `node_modules` In My Scaffolded App

You likely created the app inside another `pnpm` workspace.

Run from the parent directory:

<CodeGroup>

```bash pnpm
pnpm --dir my-app --ignore-workspace install
pnpm --dir my-app --ignore-workspace run dev
```

```bash npm
cd my-app
npm install
npm run dev
```

</CodeGroup>

---

## Web Bluetooth Is Unavailable

Check the following:

- Use Chrome or Edge
- Run on `https://` or `localhost`
- Make sure Bluetooth is enabled on the machine
- Do not expect this workflow to work in Safari or iOS

---

## `loadWasmBackend()` Returned `null`

Make sure your app is serving the packaged `pkg/rppg_wasm.js` and
`pkg/rppg_wasm_bg.wasm` assets from a path the browser can reach.

If you are unsure, compare your app with the scaffolded `rppg-demo` app.

---

## `initEegWasm()` Failed

Your app is probably not serving the packaged `wasm/` assets from
`@elata-biosciences/eeg-web` correctly.

Compare your asset layout with the scaffolded `eeg-demo` app.

<Tip>
  If you are using Vite, the two common fixes are: add `vite-plugin-wasm` and `vite-plugin-top-level-await`, or import the WASM asset URL directly and pass it to `initEegWasm(wasmUrl)`.
</Tip>

## App Store Upload Blocked: "Elata Sensor SDK Not Detected"

The app store scans every uploaded bundle and requires a real, called integration
of an Elata sensor SDK (`@elata-biosciences/rppg-web` or `@elata-biosciences/eeg-web`).
The scan only inspects the files inside your zip, so the SDK must ship in the
bundle itself.

Common causes:

- The SDK is loaded from a CDN `<script>` tag instead of being bundled. This will not pass the scan.
- The SDK's WASM assets (for example `pkg/rppg_wasm_bg.wasm`) are missing from the zip.
- A hand-written `elata-sdk.js`-style stub is included instead of the published package.
- The SDK is installed but never called. Your code must actually invoke it, for example `createRppgSession(...)`.

The fastest fix is to start from a scaffolded app, which bundles everything correctly:

```bash
npm create @elata-biosciences/elata-demo my-app
```

If your app has no build step (plain `index.html` + `script.js`), vendor the SDK
into your app folder instead:

```bash
npm install @elata-biosciences/rppg-web esbuild
npx esbuild node_modules/@elata-biosciences/rppg-web/dist/index.js \
  --bundle --format=esm --outfile=vendor/rppg-web.js
cp -r node_modules/@elata-biosciences/rppg-web/pkg pkg
```

Then load your script as a module and import from the vendored file:

```html
<script type="module" src="script.js"></script>
```

```js
import { createRppgSession } from './vendor/rppg-web.js';
```

Zip the whole app folder, including `pkg/` and `vendor/`, and upload that zip.

<Tip>
  The `pkg/` folder must sit at the root of your zip — the SDK loads
  `/pkg/rppg_wasm.js` at runtime. For `@elata-biosciences/eeg-web`, vendor its
  `wasm/` assets the same way.
</Tip>

title: "Quickstart"
description: "Build a biosignal app and publish it to Elata."
---

This guide takes you from nothing to a submitted app. You'll need Node.js 20 or
newer and a webcam.

<Warning>
  **Known issue:** the current npm release of `create-elata-demo` (0.12.1)
  fails to start. A fix is coming in the next release. Until then, follow
  [Add rPPG to an existing app](/sdk/tutorials/rppg-existing-app) to set up
  the SDK in your own web app instead. See [What's live](/overview/status).
</Warning>

<Steps>
  <Step title="Scaffold an app">
    Create a camera heart-rate (rPPG) starter app:

    ```bash
    npm create @elata-biosciences/elata-demo my-app -- --template rppg
    cd my-app
    npm install
    ```

    Prefer EEG, headband PPG, or a game? See the [template list](/sdk/create-elata-demo).
  </Step>

  <Step title="Run it locally">
    ```bash
    npm run dev
    ```

    Open the local URL, allow camera access, and you should see a live pulse signal.
  </Step>

  <Step title="Make it yours">
    Edit the app in `src/`. The [rPPG guide](/sdk/guides/rppg-browser) explains the session API, and the [platform APIs](/apps/platform/host-bridge) add purchases, saved progress, and scores.
  </Step>

  <Step title="Add a version">
    Create `public/elata.json`:

    ```json
    { "version": "1.0.0" }
    ```

    See [elata.json](/apps/build/elata-json).
  </Step>

  <Step title="Build the upload">
    ```bash
    npm run build:zip
    ```

    This writes `app.zip` with `index.html` at its root.
  </Step>

  <Step title="Publish">
    Go to [app.elata.bio/build-app](https://app.elata.bio/build-app), register your app name, upload `app.zip`, try it in the play window, add an icon and header image, and submit for review. The full walkthrough is in [Publish your app](/apps/build/launch-your-app).
  </Step>
</Steps>

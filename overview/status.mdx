<Info>

</Info>

| Label | Meaning |
| --- | --- |
| **Live** | Available now to everyone. |
| **Experimental** | Usable, but may change or have limits. |
| **Planned** | Direction we're working toward. Not available yet. |
| **Retired** | Removed. Listed so old links and posts make sense. |

## Elata SDK

Repository APIs and published packages can differ. Check the installed package version and release notes before using source-only APIs; publication labels below are not a guarantee that every current-source feature is in the npm release.

| Capability | Status | Notes |
| --- | --- | --- |
| `rppg-web`, `eeg-web`, `eeg-web-ble`, `ppg-web` | Live | On npm. [SDK overview](/sdk/overview) |
| `app-metrics`, `app-payments` | Live | On npm |
| `create-elata-demo` (starter apps) | Packaging blocker in repository version 0.12.1 | Missing `app-metrics` version metadata prevents the packaged CLI from starting. Verify a fixed release before using it. |
| `app-state` | Experimental | Not on npm yet. Apps can use the [`elata:state:*` messages](/apps/platform/app-state) directly. |
| `biosignal-session`, `biosignal-analytics`, `rppg-models-web` | Experimental | Source code only, not on npm yet. APIs may change. |
| Muse 2, Muse S, Muse S (Athena) over Web Bluetooth | Live | Chrome or Edge. [Devices](/users/devices) |
| Any webcam for rPPG | Live | |

## Data and research

| Capability | Status | Notes |
| --- | --- | --- |
| On-device processing of raw signals | Live | Raw signals do not need to leave the device |
| Local session storage, session detail, and on-device analytics | Experimental; disabled in production | Implemented on `feat/long-local-analytics` behind a developer flag. Recordings stay in that browser. [Local sessions and insights](/users/local-sessions-and-insights) |
| Federated learning (training models without collecting raw data) | Planned | Research direction. Not part of the live product. [Research directions](/overview/science/research-directions) |

## ELTA token

| Capability | Status | Notes |
| --- | --- | --- |
| ELTA token on Base | Live | Deployed, with no official liquidity pool yet. [ELTA token](/overview/elta-token) |

Elata's wider on-chain protocol (staking, app tokens, governance) is not part of
the live product. Its source is in the public
[elata-protocol](https://github.com/Elata-Biosciences/elata-protocol)
repository, which notes it is pending an external audit.

## Retired from the current product

App tokens, staking, and governance are retired for now, with a planned return later. No return date or final design is committed. Earlier documentation is historical; it does not describe today's publishing or payment flow. Other archived projects are listed separately.

| Capability | What replaced it |
| --- | --- |
| Launching a token for each app, bonding curves, and trading app tokens | Apps are registered on Elata with a one-time fee; no token is launched |
| Staking for apps, tournaments, and veELTA pages in these docs | Not part of the live product |
| "Premium content" | [In-app purchases](/apps/platform/in-app-purchases) and [subscriptions](/apps/platform/subscriptions) |
| The API Reference tab | [Host bridge](/apps/platform/host-bridge) for builders |
| ElataEEG hardware, ZORP, AgentForge, NewsReader | Archived projects. See the [Archive](/archive/overview). |

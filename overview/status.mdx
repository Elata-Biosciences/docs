This page is the single source of truth for what you can use today. Other pages
link here instead of repeating it.

| Label | Meaning |
| --- | --- |
| **Live** | Available now to everyone. |
| **Experimental** | Usable, but may change or have limits. |
| **Planned** | Direction we're working toward. Not available yet. |
| **Retired** | Removed. Listed so old links and posts make sense. |

## Elata (app.elata.bio)

| Capability | Status | Notes |
| --- | --- | --- |
| Browse, play, save, review, and follow apps | Live | [Explore apps](/users/explore-apps) |
| Publish web apps (Build an App wizard, review, sandboxed hosting) | Live | [Quickstart](/apps/quickstart) |
| Sign in with social login or an existing wallet | Live | |
| Elata Points, quests, referrals, leaderboard | Live | [Points](/overview/points) |
| Biometric Score, consent, and Insights | Live | Opt-in. [Privacy and consent](/overview/privacy-and-consent) |
| Reminders from apps (notifications) | Live | Delivered by Elata, never by the app directly |
| In-app purchases (USDC) | Deployment-dependent | The overhaul checkout uses the USDC splitter on Base; availability requires payment configuration. Check the deployed checkout's network. [In-app purchases](/apps/platform/in-app-purchases) |
| App subscriptions and Elata membership | Experimental | App subscriptions use manual calendar-month payments through the Base splitter. Membership is a separate checkout whose network and payment methods depend on deployment. Unconfigured checkout may show "Coming soon". [Membership and purchases](/users/membership-and-purchases) |

## ELTA token

| Capability | Status | Notes |
| --- | --- | --- |
| ELTA token on Base | Live | Deployed, with no official liquidity pool yet. [ELTA token](/overview/elta-token) |

Elata's wider on-chain protocol (staking, app tokens, governance) is not part of
the live product. Its source is in the public
[elata-protocol](https://github.com/Elata-Biosciences/elata-protocol)
repository, which notes it is pending an external audit.

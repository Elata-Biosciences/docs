## Give feedback

- **About an app:** leave a review or a comment on its page on Elata, or use the app's own feedback button if it has one.
- **About Elata itself:** use the feedback button on [app.elata.bio](https://app.elata.bio), or tell us on Discord.
- **Report a problem with an app:** see [Help](/users/help).
- **Email:** [info@elata.bio](mailto:info@elata.bio)

---

## Contribute

The Elata SDK is open source. You can:

- Report bugs and request features in [GitHub issues](https://github.com/Elata-Biosciences/elata-bio-sdk/issues)
- Add support for a new headset by following [Device integration](/integrate)
- Improve these docs: the [docs repository](https://github.com/Elata-Biosciences/docs) is public

Other public projects are on [Elata's GitHub](https://github.com/Elata-Biosciences).

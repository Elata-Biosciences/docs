## Common fixes

| Problem | Try |
| --- | --- |
| Camera app shows no pulse | Face a light source, sit still, and check the browser has camera permission |
| Headband won't connect | Use Chrome or Edge, turn on Bluetooth, charge the headband, and pair from inside the app |
| "Bluetooth not supported" | Safari and iOS browsers don't support Web Bluetooth; use a desktop or Android device with Chrome or Edge |
| Readings jump around | See the fit and lighting tips on [Devices](/users/devices) |
| My progress is missing | Make sure you're signed in to the same account; progress is saved per account |
| A purchase didn't unlock | Reload the app. If it's still locked, contact support with the app name and time of purchase |

## Get support

- **Feedback button:** use the feedback button on [app.elata.bio](https://app.elata.bio). Many apps also open it from their own menus.
- **Discord:** ask the community and the team on [Discord](https://discord.gg/yGxZpswpjS).
- **Email:** [info@elata.bio](mailto:info@elata.bio)

---

## Report an app

If an app is broken, misleading, unsafe, or breaks the
[submission policy](/apps/build/review-and-policy), send the app's name and what
happened through the feedback button or to
[info@elata.bio](mailto:info@elata.bio). Every app on Elata is reviewed before
release, and reports help keep it that way.

---

## Security issues

If you find a security problem in Elata itself, please report it privately to
[info@elata.bio](mailto:info@elata.bio) rather than posting it publicly.

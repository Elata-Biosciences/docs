<a id="common-fixes"></a>

## Correcciones comunes

| Problema | Prueba |
| --- | --- |
| La aplicación de la cámara no muestra pulso | Mire hacia una fuente de luz, siéntese quieto y verifique que el navegador tenga permiso para la cámara |
| La diadema no se conecta | Use Chrome o Edge, active Bluetooth, cargue la diadema y emparéjela desde dentro de la aplicación |
| "Bluetooth no compatible" | Safari y los navegadores iOS no son compatibles con Web Bluetooth; use una computadora de escritorio o un dispositivo Android con Chrome o Edge |
| Las lecturas saltan | Vea los consejos de ajuste e iluminación en [Dispositivos](/es/users/devices) |
| Falta mi progreso | Asegúrate de haber iniciado sesión en la misma cuenta; el progreso se guarda por cuenta |
| Una compra no se desbloqueó | Vuelve a cargar la aplicación. Si aún está bloqueado, comuníquese con soporte técnico con el nombre de la aplicación y la hora de compra |

<a id="get-support"></a>

## Obtenga soporte

- **Botón de comentarios:** use el botón de comentarios en [app.elata.bio](https://app.elata.bio). Muchas aplicaciones también lo abren desde sus propios menús.
- **Discord:** pregunta a la comunidad y al equipo en [Discord](https://discord.gg/yGxZpswpjS).
- **Correo electrónico:** [info@elata.bio](mailto:info@elata.bio)

<a id="report-an-app"></a>

## Reportar una aplicación

Si una aplicación no funciona, es engañosa, insegura o infringe la política de envío
[](/es/apps/build/review-and-policy), envíe el nombre de la aplicación y qué
sucedió a través del botón de comentarios o al
[info@elata.bio](mailto:info@elata.bio). Cada aplicación en Elata se revisa antes
lanzamiento, y los informes ayudan a que siga siendo así.

<a id="security-issues"></a>

## Problemas de seguridad

Si encuentra un problema de seguridad en Elata , infórmelo de forma privada a
[info@elata.bio](mailto:info@elata.bio) en lugar de publicarlo públicamente.

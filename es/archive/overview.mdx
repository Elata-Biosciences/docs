El Archivo conserva proyectos anteriores de código abierto de Elata. Ya no están en desarrollo activo, pero su código es público y estas páginas se conservan como referencia. Para conocer lo que está disponible hoy, consulte [Qué hay en vivo](/es/overview/status).

## Funciones retiradas

Los tokens de aplicaciones, las apuestas y la gobernanza se retiraron del producto actual por ahora y se espera que regresen más adelante. El diseño y el calendario futuros no están comprometidos. Los enlaces antiguos redirigen a la guía actual en lugar de dar a entender que estas funciones se pueden utilizar en la actualidad.

| Retirado | hoy |
| --- | --- |
| Lanzamiento de un token para cada aplicación, curvas de vinculación y tokens de aplicaciones comerciales | Las aplicaciones se registran con una tarifa única; no se lanza ningún token |
| Apuestas por aplicaciones, torneos y veELTA páginas | No forma parte del producto en vivo. |
| «Contenido prémium» | [Compras dentro de aplicaciones](/es/apps/platform/in-app-purchases) y [suscripciones](/es/apps/platform/subscriptions) |
| La pestaña Referencia de API | [Puente de host](/es/apps/platform/host-bridge) |

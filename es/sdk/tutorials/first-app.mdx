Utilice esta página si es nuevo en SDK y desea una aplicación andamiada exitosa
ejecutándose localmente antes de integrar algo manualmente.

Si desea el mapa completo (**rPPG principal**, **EEG opcional**, **Bluetooth a
conecte un auricular**) con andamio versus paso a paso versus descripción general, use
[la descripción general SDK ](/es/sdk/overview).

El objetivo es simple: ejecutar localmente una aplicación que funcione, entender cuál
La plantilla asigna el flujo de trabajo del sensor y sabe adónde ir a continuación.

<a id="what-you-will-build"></a>

## Lo que construirás

Creará una de las aplicaciones iniciales publicadas con
`@elata-biosciences/create-elata-demo`.

Elija la plantilla que coincida con su objetivo:

- `rppg-demo`: **principal**: pulso basado en cámara/rPPG aplicación
- `eeg-demo`: navegador EEG procesamiento, con soporte Muse Web Bluetooth 
- `eeg-ble`: Bluetooth primero EEG inicial para un auricular compatible con Muse
- `ppg-demo`: frecuencia cardíaca y HRV del sensor Muse de la diadema PPG 
- `pulse-game`: un rPPG juego que se ejecuta en un iframe de espacio aislado y guarda puntuaciones, de la misma manera que se ejecutan las aplicaciones en Elata

<a id="why-start-here"></a>

## Por qué empezar aquí

Este es el valor predeterminado recomendado porque le brinda:

- una estructura de aplicación funcional
- versiones de paquetes compatibles fijadas
- una implementación de referencia con la que puedes comparar tu propia aplicación

Haga esto antes de integrar SDK en una aplicación existente.

<a id="step-1-choose-a-template"></a>

## Paso 1: Elige una plantilla

Utilice esta tabla de decisiones:

| Si quieres... | Elige |
| --- | --- |
| Cree la aplicación predeterminada basada en cámara (sin hardware adicional) | `rppg-demo` |
| Agregar navegador EEG solamente (muestras sintéticas o sin conexión primero) | `eeg-demo` |
| Habilite un auricular compatible con Musea través de Bluetooth (Chrome/Edge) | `eeg-ble` |
| Lee la frecuencia cardíaca y HRV desde una diadema Muse  | `ppg-demo` |
| Vea el patrón Elata completo (iframe en espacio aislado + puntuaciones guardadas) | `pulse-game` |

Si no está seguro, comience con `rppg-demo`.

<a id="step-2-scaffold-the-app"></a>

## Paso 2: Organice la aplicación

Comience con el selector interactivo:

<CodeGroup>

```bash pnpm
pnpm create @elata-biosciences/elata-demo my-app
```

```bash npm
npm create @elata-biosciences/elata-demo my-app
```

</CodeGroup>

Si prefiere la ruta predeterminada explícita, utilice scaffolding `rppg-demo`
directamente:

<CodeGroup>

```bash pnpm
pnpm create @elata-biosciences/elata-demo my-app -- --template rppg
```

```bash npm
npm create @elata-biosciences/elata-demo my-app -- --template rppg
```

</CodeGroup>

Si desea ver la lista completa de plantillas primero:

<CodeGroup>

```bash pnpm
pnpm dlx @elata-biosciences/create-elata-demo --list-templates
```

```bash npm
npx @elata-biosciences/create-elata-demo --list-templates
```

</CodeGroup>

El alias completo y la matriz de plantilla se encuentran en [create-elata-demo](/es/sdk/create-elata-demo).

<a id="step-3-install-and-run"></a>

## Paso 3: instalar y ejecutar

Copie **una columna** (pnpm o npm), luego ejecute cada línea en orden:

<CodeGroup>

```bash pnpm
cd my-app
pnpm install
pnpm run dev
```

```bash npm
cd my-app
npm install
npm run dev
```

</CodeGroup>

<a id="step-4-confirm-what-you-have"></a>

## Paso 4: Confirma lo que tienes

Una vez que se inicie la aplicación, verifique el comportamiento esperado:

- `rppg-demo`: solicita acceso a la cámara e inicia una sesión estilo pulso
- `eeg-demo`: carga el procesamiento EEG en el navegador y muestra la salida basada en datos sintéticos
- `eeg-ble`: agrega emparejamiento y transmisión por Bluetooth para auriculares compatibles con Museademás de EEG
- `ppg-demo`: conecta una diadema Muse y muestra diagnósticos BPM, RMSSD y PPG en vivo
- `pulse-game`: ejecuta el juego dentro de un iframe de espacio aislado y guarda las puntuaciones a través de un host local, como lo hace Elata .

Si su objetivo es solo la evaluación, deténgase aquí primero y aprenda de lo generado.
aplicación antes de integrarla en una base de código existente.

<a id="step-5-understand-the-generated-app"></a>

## Paso 5: Comprenda la aplicación generada

Cada aplicación estructurada te ofrece:

- un mínimo Vite + React caparazón
- Elata paquetes ya conectados
- a `README.md` con notas específicas de la plantilla
- un script `build` para que puedas confirmar que la aplicación se compila limpiamente
- un script `build:zip` que empaqueta la aplicación para [cargarla en Elata](/es/apps/build/launch-your-app)

Esta debe ser su línea de base conocida y buena.

Cuando una integración manual salga mal más adelante, compare su aplicación con esto
generó uno antes de asumir que el paquete está roto.

<a id="common-gotcha-scaffolding-inside-another-pnpm-workspace"></a>

## Problema común: andamio dentro de otro `pnpm` Espacio de trabajo

Si crea `my-app` dentro de otro repositorio que ya tiene un
`pnpm-workspace.yaml`, `pnpm install` puede adjuntarse al espacio de trabajo principal
en lugar de la aplicación generada.

Ejecute estos **una línea a la vez** desde el directorio principal (ajuste `my-app` si es necesario):

<CodeGroup>

```bash pnpm
pnpm --dir my-app --ignore-workspace install
pnpm --dir my-app --ignore-workspace run dev
```

```bash npm
cd my-app
npm install
npm run dev
```

</CodeGroup>

<a id="where-to-go-next"></a>

## Adónde ir a continuación

Ya tienes un andamio en funcionamiento. El orden recomendado es **cámara rPPG
primero** (la aplicación principal de la mayoría de las personas), **navegador EEG segundo si el producto lo necesita
señales cerebrales**, luego **Web Bluetooth para conectar unos auriculares** (transporte en la parte superior
de EEG). Cada paso se divide de la misma manera: **permanecer en el andamio** o **integrar
en una aplicación que ya tienes**.

<a id="next-camera-rppg-primary"></a>

### Siguiente: Cámara (rPPG): principal

Elige la fila que más te convenga:

| Su situación | Qué hacer a continuación |
| --- | --- |
| **Nueva aplicación**: seguirá construyendo a partir del `rppg-demo` andamio generado | Utilice [rPPG en una aplicación de navegador](/es/sdk/guides/rppg-browser) para el modelo de integración, luego [rppg-web](/es/sdk/rppg-web/getting-started) mientras cambias la plantilla. Para detalles del andamio CLI : [create-elata-demo](/es/sdk/create-elata-demo). |
| **Aplicación existente**: necesitas rPPG dentro de un código base que ya envías | Seguir [Agregar basado en cámara rPPG A una aplicación de navegador existente](/es/sdk/tutorials/rppg-existing-app) paso a paso. |

<a id="then-browser-eeg-optional-no-headset-yet"></a>

### Luego: Navegador EEG: opcional (aún no hay auriculares)

| Su situación | Qué hacer a continuación |

| **Aplicación existente** | [Agregar EEG a una aplicación de navegador existente](/es/sdk/tutorials/eeg-existing-app). |

<a id="then-enable-bluetooth-headset-muse-compatible"></a>

### Luego: Habilite los auriculares Bluetooth (Muse-compatible)

| Su situación | Qué hacer a continuación |
| --- | --- |

| **Aplicación existente** | [Stream Muse-Compatible EEG Over Web Bluetooth](/es/sdk/tutorials/eeg-ble-live-stream). Si WASM aún no está cableado, haga primero la fila EEG de arriba. |

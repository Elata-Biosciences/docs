<a id="package-and-tooling-expectations"></a>

## Expectativas de paquetes y herramientas

| Superficie | Tiempo de ejecución del navegador | Node.js | Notas |
| --- | --- | --- | --- |
| `@elata-biosciences/create-elata-demo` | n/a | `>= 18` | Solo andamio CLI |
| `@elata-biosciences/eeg-web` | navegador moderno con WebAssembly | `>= 20` | El uso del navegador depende de la entrega de activos WASM empaquetados. |
| `@elata-biosciences/eeg-web-ble` | Chrome o Edge con Web Bluetooth | `>= 20` | depende de `@elata-biosciences/eeg-web` |
| `@elata-biosciences/rppg-web` | navegador moderno con cámara y WebAssembly | `>= 20` | Los recursos empaquetados WASM deben ser accesibles mediante el navegador. |
| `@elata-biosciences/ppg-web` | Chrome o Edge con Web Bluetooth | `>= 20` | circula en el transporte `eeg-web-ble`  |
| `@elata-biosciences/biosignal-session` | navegador moderno con Web Workers | `>= 20` | La grabación necesita un host que proporcione el lado de almacenamiento. |
| `@elata-biosciences/biosignal-analytics` | navegador moderno con WebAssembly | `>= 20` | Los recursos empaquetados WASM deben ser accesibles mediante el navegador. |
| `@elata-biosciences/app-payments`, `app-state`, `app-metrics` | cualquier navegador moderno | `>= 20` | solo funciona dentro del marco Elata |

<a id="browser-support"></a>

## Soporte del navegador

| Flujo de trabajo | Cromo/borde | macOS Safari | Safari iOS | Notas |
| --- | --- | --- | --- | --- |
| `create-elata-demo` | n/a | n/a | n/a | el andamio se ejecuta en Node |
| EEG WASM con `eeg-web` | Compatible | Compatible | Compatible | requiere activos empaquetados `wasm/`  |
| Navegador Muse BLE con `eeg-web-ble` | Soportado en contexto seguro | No compatible | No compatible | requiere conexión Bluetooth |
| rPPG con `rppg-web` | Compatible | Compatible | Compatible con permisos de cámara. | requiere activos empaquetados `pkg/`  |
| Diadema PPG con `ppg-web` | Soportado en contexto seguro | No compatible | No compatible | requiere conexión Bluetooth |

<a id="web-bluetooth-expectations"></a>

## Expectativas de Bluetooth web

- Utilice Chrome o Edge.
- Ejecute en `https://` o `localhost`.
- Habilite Bluetooth en la máquina.
- Espere que Safari y el navegador iOS BLE no sean compatibles con este flujo de trabajo.

<Warning>
`eeg-web-ble` requiere Web Bluetooth y un origen `https://` o `localhost`. Safari e iOS no son compatibles con los flujos de trabajo del navegador Web Bluetooth para Muse.
</Warning>

<a id="supported-device-classes"></a>

## Clases de dispositivos compatibles

- Dispositivos BLE clásicos Muse 2 y Muse S
- Dispositivos Muse S Athena protocolo v2
- Se pueden añadir otros auriculares mediante el mismo contrato de transporte. Consulte [Integración de dispositivos](/es/integrate).

<a id="safari-and-ios-notes"></a>

## Notas de Safari e iOS

- `eeg-web` se puede utilizar como paquete WASM del lado del navegador en Safari cuando su aplicación ofrece correctamente sus activos empaquetados.
- `eeg-web-ble` no es un flujo de trabajo del navegador Safari o iOS. Utilice un shell de aplicación nativo con CoreBluetooth o una aplicación puente complementaria que transmita fotogramas a través de WebSocket.
- `rppg-web` se puede ejecutar en Safari e iOS, pero los permisos de la cámara y la entrega del paquete WASM aún deben ser correctos.

<a id="package-versions"></a>

## Versiones del paquete

Los paquetes tienen versiones independientes y las últimas versiones no son automáticamente compatibles entre sí. Cuando combine paquetes, use el conjunto `create-elata-demo` pines:

| Paquete | Versión |
| --- | --- |
| `@elata-biosciences/eeg-web` | 0.12.0 |
| `@elata-biosciences/eeg-web-ble` | 0.12.0 |
| `@elata-biosciences/ppg-web` | 0.12.0 |
| `@elata-biosciences/rppg-web` | 0.14.0 |
| `@elata-biosciences/app-metrics` | 0.5.0 |

<Warning>
`eeg-web-ble@0.12.0` y `ppg-web@0.12.0` todavía declaran rangos de pares obsoletos (`eeg-web ^0.2.1`, `rppg-web ^0.3.0`). npm se detiene con un error `ERESOLVE` cuando los instala junto a las versiones anteriores. Hasta que se actualicen los rangos, instale con `npm install --legacy-peer-deps`. pnpm solo imprime una advertencia.
</Warning>

<a id="package-manager-notes"></a>

## Notas del administrador de paquetes

Las aplicaciones de demostración generadas funcionan con `pnpm` o `npm`. Para las plantillas `eeg-demo`, `eeg-ble`y `ppg-demo` , npm actualmente necesita `--legacy-peer-deps` (consulte [Versiones del paquete](#package-versions)).

Si implementa una aplicación de demostración dentro de otro espacio de trabajo `pnpm` y no la agrega a ese espacio de trabajo, use:

<CodeGroup>

```bash pnpm
pnpm --dir my-app --ignore-workspace install
pnpm --dir my-app --ignore-workspace run dev
```

```bash npm
cd my-app
npm install
npm run dev
```

</CodeGroup>

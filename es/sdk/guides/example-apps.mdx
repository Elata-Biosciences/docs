<a id="what-these-apps-demonstrate"></a>

## Lo que demuestran estas aplicaciones

Cada aplicación es un repositorio independiente que utiliza los paquetes `@elata-biosciences` publicados:

| Paquete | Propósito |
| --- | --- |
| `@elata-biosciences/eeg-web` | EEG procesamiento y modelos de señales |
| `@elata-biosciences/eeg-web-ble` | Transmisión web con diadema Bluetooth |
| `@elata-biosciences/rppg-web` | Medición de frecuencia cardíaca basada en cámara |

Estas aplicaciones son útiles como implementaciones de referencia cuando necesita ver cómo un producto real conecta las sesiones del SDK, la administración del estado, los gráficos y la limpieza.

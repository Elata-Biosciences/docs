<a id="start-here"></a>

## Empieza aquí

1. **¿Nueva aplicación o simplemente evaluando?** Utilice [`create-elata-demo`](/es/sdk/create-elata-demo). Tendrás una aplicación funcional en minutos.
2. **¿Aplicación existente?** Agregue el paquete para la capacidad que necesita, de la siguiente tabla.
3. **¿Publicando en Elata?** Agregue los paquetes [Elata ](#elata-packages) para compras, almacenamiento y puntajes.

<a id="common-mistakes"></a>

## Errores comunes

<Warning>
Estos causan la mayoría de los problemas de primera ejecución.
</Warning>

- **Instalando `eeg-web-ble` sin `eeg-web`.** El transporte Bluetooth depende de ello.
- **Esperando Web Bluetooth en Safari o en iOS.** Utilice Chrome o Edge en escritorio o Android. Consulte [Compatibilidad](/es/sdk/operations/compatibility).
- **Sirviendo sobre plano `http://`.** La cámara y el Bluetooth necesitan `https://` o `localhost`.
- **Suponiendo que una aplicación estructurada no funciona dentro de otro pnpm espacio de trabajo.** Instálalo con `pnpm --dir my-app --ignore-workspace install`.

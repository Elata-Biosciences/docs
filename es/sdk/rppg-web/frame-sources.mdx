<a id="framesource-interface"></a>

## Interfaz FrameSource

Todas las fuentes de fotogramas implementan esta interfaz:

```typescript
interface FrameSource {
  onFrame: ((frame: Frame) => void) | null;
  start(): Promise<void>;
  stop(): Promise<void>;
}

type Frame = {
  data: Uint8ClampedArray | number[];  // RGBA pixel data
  width: number;
  height: number;
  roi?: ROI;
  rois?: ROI[];
  timestampMs?: number;
};

type ROI = { x: number; y: number; w: number; h: number };
```

<a id="mediapipeframesource"></a>

## Fuente de MediaPipeFrame

Captura fotogramas de la cámara y utiliza MediaPipe para la detección de rostros, proporcionando un ROI del rostro con cada fotograma:

```typescript
import { MediaPipeFrameSource } from "@elata-biosciences/rppg-web";

const video = document.querySelector("video")!; // a playing camera <video>
const source = new MediaPipeFrameSource(video);

source.onFrame = (frame) => {
  // frame.roi contains the detected face bounding box
  // frame.data contains the camera image pixels
  console.log("Face ROI:", frame.roi);
};

await source.start();
// ... later
await source.stop();
```

<a id="mediapipefaceframesource"></a>

## Fuente de marco de cara de MediaPipe

Una variante más especializada que utiliza MediaPipe FaceLandmarker para la detección de puntos de referencia faciales. Cada cuadro lleva el ROI de la cara más los sub-ROI de la frente y las mejillas, puntos de referencia y formas combinadas:

```typescript
import { MediaPipeFaceFrameSource, loadFaceLandmarker } from "@elata-biosciences/rppg-web";

const faceLandmarker = await loadFaceLandmarker();
if (!faceLandmarker) throw new Error("Face tracking unavailable");
const source = new MediaPipeFaceFrameSource(video, faceLandmarker);

source.onFrame = (frame) => {
  // frame.rois may contain multiple face regions
  console.log("Face regions:", frame.rois?.length);
};

await source.start();
```

<a id="loadfacelandmarker"></a>

## cargarFaceLandmarker

Carga MediaPipe FaceLandmarker (con blendshapes) desde una CDN. Devuelve `null`
cuando el seguimiento facial no está disponible, por lo que puedes recurrir a `MediaPipeFrameSource`:

```typescript
import { loadFaceLandmarker } from "@elata-biosciences/rppg-web";

const faceLandmarker = await loadFaceLandmarker({
  // all optional:
  // visionCdnBase, wasmBase, modelAssetPath
});
```

## DemoRunner

`DemoRunner` organiza una fuente de fotogramas y `RppgProcessor` juntos, manejando la extracción de ROI, el enmascaramiento de piel y los informes de estadísticas:

```typescript
import { DemoRunner, MediaPipeFrameSource, RppgProcessor, loadWasmBackend } from "@elata-biosciences/rppg-web";
import type { DemoRunnerOptions } from "@elata-biosciences/rppg-web";

const backend = await loadWasmBackend();
if (!backend) throw new Error("rPPG WASM backend unavailable");
const source = new MediaPipeFrameSource(video);
const processor = new RppgProcessor(backend, 30);

const options: DemoRunnerOptions = {
  useSkinMask: true,
  onStats: (stats) => {
    console.log(`Green: ${stats.intensity}, Skin: ${stats.skinRatio}, FPS: ${stats.fps}`);
  },
};

const runner = new DemoRunner(source, processor, options);
await runner.start();

// ... later
await runner.stop();
```

<a id="demorunneroptions"></a>

### Opciones de DemoRunner

| Opción | Tipo | Predeterminado | Descripción |
|--------|------|---------|-------------|
| `roi` | `ROI \| null` | `null` | Anulación de ROI fija (nulo = usar detección de rostros) |
| `sampleRate` | `number` | - | Anular frecuencia de muestreo |
| `roiSmoothingAlpha` | `number` | - | Suavizado exponencial para fluctuación del ROI |
| `useSkinMask` | `boolean` | `false` | Aplicar mascarilla tono piel YCbCr |
| `skinRatioSmoothingAlpha` | `number` | - | Suaviza la métrica de proporción de piel |
| `onStats` | `function` | - | Devolución de llamada con estadísticas por cuadro |

<a id="roi-helper"></a>

## Ayudante de retorno de la inversión

Extraiga la intensidad promedio del canal verde de una región de interés:

```typescript
import { averageGreenInROI } from "@elata-biosciences/rppg-web";

const intensity = averageGreenInROI(frame, roi.x, roi.y, roi.w, roi.h);
```

<a id="what-it-is"></a>

## Que es

`@elata-biosciences/create-elata-demo` genera una aplicación Vite + React que funciona
cableado al Elata SDK. Es la forma más rápida de ejecutar una aplicación y
una línea de base en buen estado antes de integrar los SDK en su propio proyecto.

---

<a id="templates"></a>

## Plantillas

| Plantilla | Alias | Lo que obtienes | Hardware |
| --- | --- | --- | --- |
| `rppg-demo` | `rppg` | Pulso de cámara y rPPG arrancador. **El valor predeterminado.** | Cámara web |
| `eeg-demo` | `eeg` | Navegador EEG arrancador para cableado SDK , con Muse Web Bluetooth soporte | Muse (opcional) |
| `eeg-ble` | `ble` | Bluetooth primero EEG iniciador con el flujo de emparejamiento del navegador | Muse |
| `ppg-demo` | `ppg`, `muse-ppg` | Diadema PPG arrancador mostrando BPM, RMSSD y diagnóstico en vivo | Muse |
| `pulse-game` | `pulse`, `recovery` | rPPG juego de recuperación que se ejecuta en un iframe de espacio aislado y guarda puntuaciones con `app-metrics`, de extremo a extremo | Cámara web |

<Tip>
¿Edificio para Elata? `pulse-game` muestra el patrón Elata completo:
  la aplicación se ejecuta en un iframe y se comunica con un host a través del puente de métricas
  [](/es/apps/platform/metrics-and-scores).
</Tip>

<a id="usage"></a>

## Uso

<CodeGroup>

```bash npm
# Interactive: pick a template, then a project name
npm create @elata-biosciences/elata-demo my-app

# Pick a template directly
npm create @elata-biosciences/elata-demo my-app -- --template rppg
npm create @elata-biosciences/elata-demo my-app -- --template eeg-ble
npm create @elata-biosciences/elata-demo my-app -- --template ppg
npm create @elata-biosciences/elata-demo my-app -- --template pulse-game

# List templates
npx @elata-biosciences/create-elata-demo --list-templates
```

```bash pnpm
pnpm create @elata-biosciences/elata-demo my-app
pnpm create @elata-biosciences/elata-demo my-app -- --template rppg
pnpm dlx @elata-biosciences/create-elata-demo --list-templates
```

</CodeGroup>

| Bandera | Significado |
| --- | --- |
| `--template <name>` o `--template=<name>` | Elija una plantilla o alias |
| `--list-templates` | Imprime las plantillas disponibles |

Sin `--template`, CLI le pide que elija uno cuando se ejecuta de forma interactiva, y
usa `rppg-demo` en caso contrario. Si omite el directorio del proyecto, le solicitará
un nombre.

<a id="what-you-get"></a>

## Lo que obtienes

Cada aplicación generada incluye:

- una aplicación Vite + React + TypeScript 
- Elata paquetes anclados a un conjunto de versiones compatibles
- una plantilla específica `README.md`
- `npm run dev`: inicia el servidor de desarrollo
- `npm run build`: escriba la verificación y construya en `dist/`
- `npm run build:zip`: compila y escribe `app.zip`, listo para [cargar en Elata](/es/apps/build/launch-your-app)

```bash
cd my-app
npm install
npm run dev
```

<a id="inside-another-pnpm-workspace"></a>

## Dentro de otro pnpm espacio de trabajo

Si realiza un scaffolding dentro de un espacio de trabajo `pnpm` existente que no incluye el nuevo
carpeta, instálelo y ejecútelo fuera del espacio de trabajo:

```bash
pnpm --dir my-app --ignore-workspace install
pnpm --dir my-app --ignore-workspace run dev
```

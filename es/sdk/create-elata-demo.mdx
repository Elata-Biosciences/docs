<a id="what-it-is"></a>

## que es

`@elata-biosciences/create-elata-demo` genera una aplicación Vite + React funcional conectada al SDK de Elata. Es la forma más rápida de ejecutar una aplicación y una base de referencia conocida antes de integrar los SDK en su propio proyecto.

---

<a id="templates"></a>

## Plantillas

| Plantilla | Alias | lo que obtienes | Hardware |
| --- | --- | --- | --- |
| `rppg-demo` | `rppg` | Pulso de cámara y arranque rPPG . **El valor predeterminado.** | cámara web |
| `eeg-demo` | `eeg` | Navegador EEG iniciador para cableado SDK, con soporte Muse Web Bluetooth | Musa (opcional) |
| `eeg-ble` | `ble` | Iniciador Bluetooth EEG primero con el flujo de emparejamiento del navegador | musa |
| `ppg-demo` | `ppg`, `muse-ppg` | Arrancador de diadema PPG que muestra BPM, RMSSD y diagnóstico en vivo | musa |
| `pulse-game` | `pulse`, `recovery` | rPPG juego de recuperación que se ejecuta en un iframe de espacio aislado y guarda puntuaciones con `app-metrics`, de principio a fin | cámara web |

<Tip>
¿Edificio para Elata? `pulse-game` muestra el patrón Elata completo: la aplicación se ejecuta en un iframe y habla con un host a través del puente de métricas [](/es/apps/platform/metrics-and-scores).
</Tip>

<a id="usage"></a>

## Uso

<CodeGroup>

```bash npm
# Interactive: pick a template, then a project name
npm create @elata-biosciences/elata-demo my-app

# Pick a template directly
npm create @elata-biosciences/elata-demo my-app -- --template rppg
npm create @elata-biosciences/elata-demo my-app -- --template eeg-ble
npm create @elata-biosciences/elata-demo my-app -- --template ppg
npm create @elata-biosciences/elata-demo my-app -- --template pulse-game

# List templates
npx @elata-biosciences/create-elata-demo --list-templates
```

```bash pnpm
pnpm create @elata-biosciences/elata-demo my-app
pnpm create @elata-biosciences/elata-demo my-app -- --template rppg
pnpm dlx @elata-biosciences/create-elata-demo --list-templates
```

</CodeGroup>

| Bandera | Significado |
| --- | --- |
| `--template <name>` o `--template=<name>` | Elija una plantilla o alias |
| `--list-templates` | Imprime las plantillas disponibles |

Sin `--template`, la CLI le pide que elija uno cuando se ejecuta de forma interactiva y usa `rppg-demo` en caso contrario. Si omite el directorio del proyecto, le pedirá un nombre.

<a id="what-you-get"></a>

## lo que obtienes

Cada aplicación generada incluye:

- una aplicación Vite + React + TypeScript
- Paquetes de Elata anclados a un conjunto de versiones compatibles
- una plantilla específica `README.md`
- `npm run dev`: inicia el servidor de desarrollo
- `npm run build`: escriba la verificación y construya en `dist/`
- `npm run build:zip`: construye y escribe `app.zip`, listo para [subir a Elata](/es/apps/build/launch-your-app)

```bash
cd my-app
npm install
npm run dev
```

<a id="inside-another-pnpm-workspace"></a>

## Dentro de otro espacio de trabajo pnpm

Si realiza scaffolding dentro de un espacio de trabajo `pnpm` existente que no incluye la nueva carpeta, instálelo y ejecútelo fuera del espacio de trabajo:

```bash
pnpm --dir my-app --ignore-workspace install
pnpm --dir my-app --ignore-workspace run dev
```

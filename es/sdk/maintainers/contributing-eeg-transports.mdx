## Resumen

- **`@elata-biosciences/eeg-web-ble`** es el **Web Bluetooth** paquete de transporte compartido. Incluye una implementación **integrada Muse** y no está **limitada a Muse** para contribuciones.
- **Diseño:** `src/transport/` (`BleTransport`) vs `src/devices/muse/` (Muse protocolo). Agregue nuevos proveedores en `src/devices/<vendor>/`.
- El nuevo hardware debería converger en **`HeadbandTransport`** y **`HeadbandFrameV1`** de **`@elata-biosciences/eeg-web`**.
- Prefiere un **nuevo módulo de dispositivo** en `eeg-web-ble`, un **`BleTransport` `device` adaptador**, o un **paquete hermano** bajo `packages/` cuando la integración es grande o necesita un puente.

<a id="recommended-default-for-generally-useful-devices"></a>

## Valor predeterminado recomendado para dispositivos generalmente útiles

Utilice una contribución ascendente **dentro de `eeg-web-ble`**:

- `packages/eeg-web-ble/src/devices/<vendor>/...` para protocolo, GATT y lógica de decodificación
- reutilización `src/transport/bleTransport.ts` para transporte y comportamiento del marco
Adaptadores tipo- contra `BleDeviceLike` exportados desde `@elata-biosciences/eeg-web-ble`
- agregar pruebas Web Bluetooth simuladas en `src/__tests__/`
- actualizar los documentos del paquete, los documentos del mantenedor y los documentos SDK juntos
- agregue un conjunto de cambios si el cambio debe enviarse

Abra un problema GitHub antes de cambios importantes en el protocolo o el paquete. Siga el repositorio **[Guía de CONTRIBUCIÓN](https://github.com/Elata-Biosciences/elata-bio-sdk/blob/main/CONTRIBUTING.md)** para relaciones públicas, pruebas y conjuntos de cambios.

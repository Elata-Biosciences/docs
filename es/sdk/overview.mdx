## Elata SDK

El Elata SDK es un conjunto de npm paquetes para capturar y procesar bioseñales en el
navegador. Los paquetes se construyen en cajas Rust compiladas en WebAssembly, por lo que indica
el procesamiento se ejecuta en el dispositivo del usuario.

<Info>
  **Repositorio**: [github.com/Elata-Biosciences/elata-bio-sdk](https://github.com/Elata-Biosciences/elata-bio-sdk) · **npm**: [`@elata-biosciences`](https://www.npmjs.com/org/elata-biosciences)
</Info>

---

<a id="quick-start"></a>

## Inicio rápido

El camino más rápido es crear una aplicación inicial:

```bash
# Interactive template picker
npm create @elata-biosciences/elata-demo my-app

# Or pick one directly
npm create @elata-biosciences/elata-demo my-app -- --template rppg
```

```bash
cd my-app
npm install
npm run dev
```

Consulte [create-elata-demo](/es/sdk/create-elata-demo) para ver las cinco plantillas.

## Paquetes

Los paquetes "en vivo" están en npm. Los paquetes "experimentales" están disponibles como fuente
código en el repositorio [SDK ](https://github.com/Elata-Biosciences/elata-bio-sdk)
y aún no en npm. Ver [Qué hay en vivo](/es/overview/status).

<a id="sensors"></a>

### Sensores

| Paquete | Qué hace | Estado |
| --- | --- | --- |
| [`@elata-biosciences/rppg-web`](/es/sdk/rppg-web/getting-started) | Señales de frecuencia cardíaca y pulso desde una cámara web (rPPG). El punto de partida predeterminado: no se necesita hardware. | En vivo |
| [`@elata-biosciences/eeg-web`](/es/sdk/eeg-web/getting-started) | EEG procesamiento de señal, potencias de banda y modelos (WASM), más el contrato de marco de diadema compartido. | En vivo |
| [`@elata-biosciences/eeg-web-ble`](/es/sdk/eeg-web-ble/getting-started) | Conecte las diademas EEG sobre Web Bluetooth. Muse incorporado; extensible a otros dispositivos. | En vivo |
| [`@elata-biosciences/ppg-web`](/es/sdk/ppg-web/getting-started) | Frecuencia cardíaca y HRV del sensor óptico de una diadema (PPG). | En vivo |

### Grabación y análisis

| Paquete | Qué hace | Estado |
| --- | --- | --- |
| [`@elata-biosciences/biosignal-session`](/es/sdk/biosignal-session/getting-started) | Grabe sesiones de múltiples sensores en el almacenamiento local con un protocolo tolerante a fallas y Arrow fragmentos. | Experimental |

<a id="add-packages-to-an-existing-app"></a>

## Agregar paquetes a una aplicación existente

```bash
# Camera heart rate
npm install @elata-biosciences/rppg-web

# EEG over Web Bluetooth
npm install @elata-biosciences/eeg-web @elata-biosciences/eeg-web-ble

# Headband PPG heart rate and HRV
npm install @elata-biosciences/ppg-web @elata-biosciences/eeg-web @elata-biosciences/eeg-web-ble @elata-biosciences/rppg-web
```

**Requisitos**: Node.js 20 o más reciente para herramientas y un navegador moderno con soporte WebAssembly .

<a id="device-support"></a>

## Soporte de dispositivo

| Dispositivo | Protocolo | Señales | Estado |
| --- | --- | --- | --- |
| Muse 2 | BLE clásico | 4 EEG (TP9, AF7, AF8, TP10), PPG | Compatible |
| Muse S | BLE clásico | 4 EEG, PPG | Compatible |
| Muse S (Athena) | Athena | 8 EEG, óptica, acelerómetro/giroscopio | Compatible |
| Cualquier cámara web | Cámara | rPPG pulso | Compatible |

¿Quieres agregar unos auriculares? Consulte [Integración de dispositivos](/es/integrate).

<a id="rust-crates"></a>

## Rust cajas

Los paquetes se crean en cajas Rust públicas que también puedes usar directamente:

| Caja | Propósito |
| --- | --- |
| `elata-eeg-hal` | Rasgos principales del dispositivo: `EegDevice`, `SampleBuffer` |
| `elata-eeg-signal` | FFT, potencia de banda, filtrado |
| `elata-eeg-models` | Detector de golpes alfa, modelo calma |
| `elata-rppg` | rPPG núcleo de tubería |
| `elata-muse-proto` | Muse decodificación de protocolo clásico y Athena  |

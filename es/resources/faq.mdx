<a id="about-elata"></a>

## Acerca de Elata

<AccordionGroup>
  <Accordion title="¿Qué es Elata?">
Un mercado para aplicaciones de bioseñales que respetan la privacidad en [app.elata.bio](https://app.elata.bio), además del Elata SDK de código abierto para crearlas. Ver [Bienvenido](/es/overview/welcome).
  </Accordion>
  <Accordion title="¿Es Elata un producto médico?">
No. Las aplicaciones de Elata son para bienestar, juegos, aprendizaje e investigación. No diagnostican, tratan ni monitorean ninguna condición médica. Consulte [Seguridad y limitaciones](/es/users/safety-and-limitations).
  </Accordion>
  <Accordion title="que's available today?">
La página [Qué está activo](/es/overview/status) enumera todas las capacidades como activas, experimentales, planificadas o retiradas.
  </Accordion>
</AccordionGroup>

<a id="using-apps"></a>

## Usando aplicaciones

<AccordionGroup>
  <Accordion title="¿Necesito hardware especial?">
No. Las aplicaciones de cámara funcionan con cualquier cámara web. EEG y las aplicaciones de frecuencia cardíaca con diadema necesitan una diadema compatible, como Muse. Consulte [Dispositivos](/es/users/devices).
  </Accordion>
  <Accordion title="¿Qué navegadores son compatibles?">
Las aplicaciones de cámara funcionan en navegadores modernos. Las diademas Bluetooth necesitan Chrome o Edge (Web Bluetooth); Los navegadores Safari e iOS no lo admiten. Consulte [Dispositivos](/es/users/devices).
  </Accordion>
  <Accordion title="¿Necesito una billetera criptográfica?">
No. Puedes iniciar sesión con un inicio de sesión social. Conectar una billetera existente es opcional.
  </Accordion>
  <Accordion title="¿Cuesta algo?">
Navegar y jugar son gratis. Algunas aplicaciones venden elementos opcionales u ofrecen una suscripción mensual. Ver [Monetización](/es/overview/monetization).
  </Accordion>
</AccordionGroup>

<a id="privacy"></a>

## Privacidad

<AccordionGroup>
  <Accordion title="¿Mi cámara o mis datos EEG salen de mi dispositivo?">
Las señales sin procesar se procesan en su dispositivo y las aplicaciones no pueden enviarlas a ningún lado. Consulte [Privacidad y consentimiento](/es/overview/privacy-and-consent).
  </Accordion>
  <Accordion title="¿Qué es el Score biométrico?">
Una medida opcional entre aplicaciones creada a partir de resultados de sesiones derivados. Solo se crea si usted acepta y puede desactivarlo en cualquier momento. Consulte [Puntuación e información](/es/users/score-and-insights).
  </Accordion>
  <Accordion title="¿Cómo elimino mis datos?">
Correo electrónico [info@elata.bio](mailto:info@elata.bio). Ver [Tus datos](/es/users/your-data).
  </Accordion>
</AccordionGroup>

<a id="building-apps"></a>

## Creando aplicaciones

<AccordionGroup>
  <Accordion title="¿Cómo publico una aplicación?">
Cree una aplicación web con Elata SDK, luego use el asistente para crear una aplicación en [app.elata.bio/build-app](https://app.elata.bio/build-app). Consulte el [Inicio rápido](/es/apps/quickstart).
  </Accordion>
  <Accordion title="¿Mi aplicación tiene que utilizar el SDK de Elata?">
Sí. Las cargas deben utilizar al menos un paquete de sensores Elata (rPPG, EEGo PPG). Ver [Requisitos](/es/apps/build/requirements).
  </Accordion>
  <Accordion title="¿Cuánto cuesta publicar?">
Una tarifa de registro única en USDC, que se muestra en el asistente.
  </Accordion>
  <Accordion title="¿Cómo gano dinero con mi aplicación?">
Vende artículos únicos o cobra una suscripción mensual. Consulte [Monetice su aplicación](/es/apps/build/monetize).
  </Accordion>
  <Accordion title="¿Cuánto tiempo lleva la revisión?">
Cada lanzamiento se escanea automáticamente y luego un moderador lo revisa. Se le notifica en Elata y por correo electrónico cuando se aprueba.
  </Accordion>
</AccordionGroup>

<a id="points-and-the-token"></a>

## Puntos y la ficha

<AccordionGroup>
  <Accordion title="¿Qué son los Puntos Elata?">
Los puntos fuera de la cadena que obtienes por participar: jugar, revisar, crear e invitar amigos. No se pueden comprar, vender ni transferir. Ver [Puntos Elata](/es/overview/points).
  </Accordion>
  <Accordion title="¿Necesito ELTA para usar Elata?">
No. Ver [ELTA token](/es/overview/elta-token).
  </Accordion>
  <Accordion title="¿Dónde puedo comprar ELTA?">
Aún no existe un fondo de liquidez oficial. Cualquier pool que aparezca antes de un anuncio oficial no está autorizado. Consulte [ELTA token](/es/overview/elta-token).
  </Accordion>
</AccordionGroup>

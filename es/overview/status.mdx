Esta página distingue las funciones actuales, las integraciones experimentales y el trabajo futuro. Otras páginas enlazan aquí para indicar disponibilidad.

<Info>
Revisión del código: 11 de octubre de 2026. Las guías de facturación y Commerce reflejan la rama `fix/iap-system-overhaul`; no demuestran que todos los flujos estén desplegados en app.elata.bio. Confirma la interfaz y la configuración de pagos antes de cobrar.
</Info>

| Etiqueta | Significado |
| --- | --- |
| **Disponible** | Disponible ahora para todos. |
| **Experimental** | Utilizable, pero puede cambiar o tener límites. |
| **Planificado** | Dirección de trabajo; todavía no disponible. |
| **Retirado** | Eliminado; se incluye para explicar enlaces y publicaciones anteriores. |

## Elata SDK

Las API del repositorio y los paquetes publicados pueden diferir. Antes de usar API solo disponibles en el código fuente, comprueba la versión instalada y las notas de publicación; estas etiquetas no garantizan que npm incluya todas las funciones del código actual.

| Función | Estado | Notas |
| --- | --- | --- |
| `rppg-web`, `eeg-web`, `eeg-web-ble`, `ppg-web` | Disponible | En npm. [Información del SDK](/es/sdk/overview) |
| `app-metrics`, `app-payments` | Disponible | En npm |
| `create-elata-demo` (aplicaciones iniciales) | Error de empaquetado en la versión 0.12.1 del repositorio | Falta el metadato de versión de `app-metrics` y la CLI empaquetada no arranca. Comprueba una versión corregida antes de usarla. |
| `app-state` | Experimental | Aún no está en npm. Las aplicaciones pueden usar directamente los [mensajes `elata:state:*`](/es/apps/platform/app-state). |
| `biosignal-session`, `biosignal-analytics`, `rppg-models-web` | Experimental | Solo código fuente, todavía no en npm; las API pueden cambiar. |
| Muse 2, Muse S y Muse S (Athena) por Web Bluetooth | Disponible | Chrome o Edge. [Dispositivos](/es/users/devices) |
| Cámara web para rPPG | Disponible | |

## Token ELTA

| Función | Estado | Notas |

El protocolo más amplio de Elata (staking, tokens de aplicaciones y gobernanza) no forma parte del producto disponible. Su código está en el repositorio público [elata-protocol](https://github.com/Elata-Biosciences/elata-protocol), que indica que está pendiente de auditoría externa.

<a id="retired-from-the-current-product"></a>

## Funciones retiradas del producto actual

Los tokens de aplicaciones, el staking y la gobernanza se retiran por ahora y se prevé recuperarlos más adelante. No hay fecha ni diseño final comprometidos. La documentación anterior es histórica y no describe los pagos o la publicación actuales. Otros proyectos archivados se enumeran aparte.

| Función | Qué la sustituye |
| --- | --- |
| Lanzar un token por aplicación, curvas de vinculación y negociación de tokens de aplicaciones | Registro con una tarifa única, sin lanzar tokens |
| Staking de aplicaciones, torneos y páginas de veELTA | Fuera del producto disponible |
| «Contenido prémium» | [Compras dentro de aplicaciones](/es/apps/platform/in-app-purchases) y [suscripciones](/es/apps/platform/subscriptions) |
| Pestaña API Reference | [Puente del anfitrión](/es/apps/platform/host-bridge) para creadores |
| Hardware ElataEEG, ZORP, AgentForge y NewsReader | Proyectos archivados. Consulta [Archivo](/es/archive/overview). |

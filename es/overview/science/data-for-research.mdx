<a id="what-data-exists"></a>

## ¿Qué datos existen?

Elata está diseñado para que las bioseñales sin procesar no necesiten salir del dispositivo del usuario. Eso da forma a los datos que existen:

| Datos | ¿Existe? | donde |
| --- | --- | --- |
| Marcos de cámara sin procesar | No recopilado por el canal del servidor de Elata | Procesado localmente |
| Crudo EEG y PPG | No recopilado por el canal del servidor de Elata; Es posible realizar grabaciones experimentales locales. | El almacenamiento del navegador del usuario cuando se habilita un host de grabación compatible |
| Resultados de sesión derivados para la puntuación biométrica | Si, con consentimiento | Elata, para usuarios que se inscriban |
| La aplicación guarda, registra y puntúa | Sí | La cuenta del usuario, en el ámbito de cada aplicación. |
| Análisis agregado de aplicaciones | Sí | Visible para el creador de cada aplicación, anónimo |

<Note>
Actualmente, Elata no ofrece conjuntos de datos de investigación ni programas de acceso a datos.
</Note>

<a id="running-your-own-study"></a>

## Realizar tu propio estudio

Los investigadores pueden utilizar las herramientas de código abierto directamente:

- **Cree un estudio como una aplicación de Elata.** Utilice el SDK para captura y procesamiento, y publíquelo en Elata para llegar a los participantes en su navegador. Su aplicación es responsable de su propio consentimiento y protocolo de estudio. Las aplicaciones no pueden enviar bioseñales sin procesar desde el dispositivo según la política de envío [Revisión y política](/es/apps/build/review-and-policy)de Elata.
- **Utilice el SDK en sus propias herramientas.** Los paquetes de sensores funcionan en cualquier aplicación web, fuera de Elata, bajo el manejo de datos de su propia institución.

<a id="recording-sessions-experimental"></a>

## Sesiones de grabación (experimentales)

<Warning>
Experimental. El SDK proporciona el contrato de grabación. La rama `feat/long-local-analytics` de la tienda de aplicaciones implementa un host de grabación local, páginas de sesión y controles de almacenamiento, pero los deshabilita explícitamente en producción.
</Warning>

`biosignal-session` registra sesiones multisensor (EEG, PPG, rPPG métricas y más) como secuencias escritas en archivos Apache Arrow, diseñados para brindar confiabilidad:

- cada fragmento lleva una suma de verificación y una identidad estable, por lo que se puede almacenar y volver a intentar de forma segura
- las brechas reales se registran como discontinuidades explícitas, nunca interpoladas
- el tiempo es un reloj de sesión única en microsegundos enteros

La grabación es local: el paquete no tiene cliente de red. La aplicación que lo incorpora decide dónde se almacenan los datos. Consulte [sesión de bioseñal](/es/sdk/biosignal-session/getting-started).

## Herramientas de análisis (experimentales)

The Archive holds earlier open-source projects from Elata. They're no longer
under active development, but their code is public and these pages are kept
for reference. For what's available today, see [What's live](/overview/status).

## Retired features

App tokens, staking, and governance are retired from the current product for now and are intended to return later. The future design and timing are not committed. Old links redirect to current guidance rather than implying these features are usable today.

| Retired | Today |
| --- | --- |
| Launching a token for each app, bonding curves, and trading app tokens | Apps are registered with a one-time fee; no token is launched |
| Staking for apps, tournaments, and veELTA pages | Not part of the live product |
| "Premium content" | [In-app purchases](/apps/platform/in-app-purchases) and [subscriptions](/apps/platform/subscriptions) |
| The API Reference tab | [Host bridge](/apps/platform/host-bridge) |

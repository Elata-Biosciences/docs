The Archive holds earlier open-source projects from Elata. They're no longer
under active development, but their code is public and these pages are kept
for reference. For what's available today, see [What's live](/overview/status).

---

## Archived projects

| Project | What it was | Code |
| --- | --- | --- |
| [AgentForge](/open-source/agentforge/overview) | Agent-based simulation framework for testing EVM smart contracts | [agentforge](https://github.com/Elata-Biosciences/agentforge) |
| [NewsReader](/open-source/newsreader/overview) | AI-assisted news scanner behind news.elata.bio | [elata-vsm-system-4](https://github.com/Elata-Biosciences/elata-vsm-system-4) |
| [ZORP](/zorp-protocol/zorp-intro) | On-chain research platform for encrypted data contribution; reached testnet in 2025 | [zorp](https://github.com/Elata-Biosciences/zorp) |
